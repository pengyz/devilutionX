# Better D1 — 设计系统综述

> 这不是一份功能规格书，是一套设计方法论。它定义了"更好的D1"是什么、不是什么，以及如何思考每一个设计决策。

## 核心命题

D1 在 1996 年创造了独一无二的体验：哥特式生存恐怖 + ARPG。30 年后，这个体验依然独特，因为没有人复制它——所有人都在做 D2。

"更好的D1"不是"更多的D1"，不是"D2化的D1"，不是"现代化的D1"。是**更深的D1**——用同样的素材，创造更有深度的体验。

## 设计哲学

### 什么是"更好"

| 不是 | 而是 |
|---|---|
| 更多内容 | 更深的体验 |
| 更高复杂度 | 更强的氛围 |
| 更现代 | 更有意义的决策 |

### 核心体验定义

玩家在 D1 中应该感受到的：

- **不安**：一种持续的、低强度的、不知道会发生什么的感觉
- **珍惜**：每一个资源都有重量，每一个决策都有代价
- **发现**：通过探索和实验理解世界，而不是被告知
- **呼吸**：紧张→峰值→释放→紧张的节奏循环
- **敬畏**：面对一个比自己强大的世界，感到渺小但不绝望

## 设计支柱（不可妥协的原则）

### 支柱 1：不安感是核心体验

玩家应该在大部分时间感到不安。不是恐惧（那是恐怖游戏），不是紧张（那是动作游戏），是**不安**——一种持续的、低强度的、不知道会发生什么的感觉。

**推论**：
- 不要给玩家完整信息
- 不要让玩家确定自己安全
- 不要让玩家觉得自己强大

### 支柱 2：稀缺是美德

每一个资源都是稀缺的：生命、法力、金钱、时间、信息。稀缺不是限制，是决策的空间。

**推论**：
- 不要让资源充足
- 不要让决策无成本
- 不要让错误可挽回

### 支柱 3：环境是角色

地牢不是背景，是游戏最大的角色。它有自己的故事、自己的意志、自己的节奏。

**推论**：
- 环境叙事和怪物设计同等重要
- 每一层都应该有独特的"性格"
- 环境应该"回应"玩家的行为

### 支柱 4：简单但深刻

不需要 100 个技能，需要 10 个有意义的技能。不需要 100 种怪物，需要 10 种有性格的怪物。

**推论**：
- 每一个元素都应该有明确的存在理由
- 每一个选择都应该有明确的代价
- 每一个系统都应该有明确的深度

### 支柱 5：尊重玩家

不要手把手教玩家，也不要浪费玩家的时间。让玩家自己学习，但不要让玩家做无意义的重复。

**推论**：
- 死亡是学习，不是惩罚
- 重复是磨练，不是浪费
- 信息是奖励，不是施舍

## D1 的独特价值（必须保留）

| 独特价值 | 为什么重要 | 如何深化 |
|---|---|---|
| 慢节奏战斗 | 每一个动作都有重量 | 让怪物行为更有深度，而不是加快节奏 |
| 资源稀缺 | 每一个决策都有代价 | 让资源管理更有趣，而不是增加资源 |
| 氛围优先 | 恐惧来自未知 | 让环境更有叙事性，而不是加更多惊吓 |
| 节奏设计 | 紧张→峰值→释放 | 让节奏更精细，而不是压缩节奏 |
| 环境叙事 | 地牢是角色不是背景 | 让环境更有互动性，而不是加更多文本 |

---

## D1 的真正缺点（执行问题，不是设计问题）

| 缺点 | 问题 | 解决方向 |
|---|---|---|
| 怪物行为简单 | 只会直线冲向玩家 | 更智能的 AI，但保持可预测性 |
| 环境互动少 | 主要是视觉背景 | 让环境成为战斗的一部分 |
| 叙事稀疏 | 得自己读所有文本 | 用环境叙事，而不是文本叙事 |
| 平衡粗糙 | 某些 build 明显更强 | 让每个 build 有独特价值，而不是平衡数值 |
| 终局无聊 | 就是刷装备 | 让终局有叙事意义，而不是数值提升 |

## 设计语言

### 视觉语言

- 暗色调为主，亮色只用于关键信息
- 像素风格一致，不要混用不同分辨率的素材
- 动画有重量感，不要过于流畅
- 环境有层次感，前景、中景、背景分明
- 灯光和阴影是最重要的视觉效果
- 有限的颜色调色板反而能创造更强的氛围

### 交互语言

- 每一个操作都有明确的反馈
- 每一个决策都有可见的后果
- 每一个资源都有清晰的价值
- 每一个状态都有直观的表示

### 叙事语言

- 环境叙事为主，文本叙事为辅
- 暗示为主，明示为辅
- 玩家发现为主，游戏告知为辅
- 氛围营造为主，剧情推进为辅

## 像素艺术作为风格选择

像素不是障碍，是优势：

**像素的优势**：
- 一致性强——容易维持统一的视觉风格
- 氛围感强——低分辨率本身就是一种"模糊"，增强未知感
- 想象空间大——玩家的大脑会"补全"像素之间的细节
- 技术门槛低——更容易迭代和实验
- 受众明确——喜欢像素的玩家本身就喜欢这种风格

**如何用像素做出惊艳的画面**：
- 灯光和阴影——D1 的黑暗本身就是最好的视觉效果
- 色彩调色板——有限的颜色反而能创造更强的氛围
- 动画节奏——慢动画比快动画更有重量感
- 环境细节——少量但有意义的细节比大量无意义的细节更好

**参考作品**：
- Blasphemous——哥特式像素艺术的极致
- Hyper Light Drifter——色彩和光影的运用
- Dead Cells——动画的重量感和流畅性
- Celeste——像素风格下的情感表达

## 红线清单

每一个设计决策都要过这个清单：

- [ ] 它让玩家更紧张/不安，还是更舒服？
- [ ] 它增加了不确定性，还是减少了？
- [ ] 它需要玩家做决策，还是替玩家做了决策？
- [ ] 它保持了稀缺感，还是增加了富余？
- [ ] 它没有打断沉浸感？
- [ ] 它符合世界观和氛围？
- [ ] 如果去掉它，游戏会变差吗？（如果不会，不要加）
- [ ] 老玩家会觉得"这就是 D1"？
- [ ] 新玩家会觉得"这和我玩过的其他游戏不一样"？

## 迭代框架

### 测试维度

| 测试维度 | 测试方法 | 成功标准 |
|---|---|---|
| 不安感 | 玩家在大部分时间是否感到不安？ | 是 |
| 稀缺感 | 玩家是否珍惜每一个资源？ | 是 |
| 决策重量 | 玩家是否在决策前犹豫？ | 是 |
| 环境叙事 | 玩家是否通过环境理解故事？ | 是 |
| 节奏感 | 玩家是否感到紧张→释放的节奏？ | 是 |
| 氛围完整性 | 玩家是否从未"出戏"？ | 是 |

### 测试原则

- 不是测试"好不好玩"（太主观），而是测试"是否符合设计支柱"
- 不是优化"玩家死了多少次"（难度指标），而是优化"玩家感到多紧张"（氛围指标）
- 不是测"玩家用了多少血瓶"（资源指标），而是测"玩家在决策上花了多少思考时间"（决策指标）

## 设计决策模板

每一个设计决策都应该记录：

```markdown
### 决策：[标题]

**问题**：[我们要解决什么问题？]

**方案**：[我们打算怎么做？]

**设计支柱检查**：
- [ ] 符合支柱 1（不安感）
- [ ] 符合支柱 2（稀缺）
- [ ] 符合支柱 3（环境是角色）
- [ ] 符合支柱 4（简单但深刻）
- [ ] 符合支柱 5（尊重玩家）

**红线检查**：
- [ ] 通过红线清单

**预期效果**：[玩家会感受到什么？]

**风险**：[可能破坏什么？]

**验证方法**：[如何测试这个决策是否正确？]
```

## 最终标准

玩家在关掉游戏之后，还会想起这个游戏的某些瞬间。不是"我刷到了什么装备"，而是"我在第 7 层听到的那个声音是什么"。

如果做到了这一点，就是一个好的 D1。

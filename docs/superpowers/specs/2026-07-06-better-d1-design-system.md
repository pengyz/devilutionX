# Better D1 — 设计系统

> D1 是 1996 年的游戏。Better D1 是 2026 年的独立游戏。同一个世界，不同的体验。

## 产品定位

**一句话**：像素风哥特生存 ARPG，用 1996 年的素材创造 2026 年的深度。

**Steam 商店描述**：
> 暗黑破坏神的经典体验，用现代设计重新包装。慢节奏战斗、资源稀缺、随机地牢——每一个决策都有重量，每一次探索都有风险。不是怀旧，是独特的游戏体验。

**目标玩家**：
- 喜欢有深度的 ARPG（不是刷刷刷）
- 喜欢像素风格（不是画面党）
- 喜欢有挑战的游戏（不是休闲玩家）
- 想体验"真正的暗黑"（不是 D3/D4 的快节奏）

**竞品对标**：
- D2R：更快节奏、更多内容、更多刷
- Path of Exile：极深的系统、极高的复杂度
- Hades：快节奏、roguelike、叙事驱动
- **Better D1 的独特位置**：慢节奏、高决策重量、哥特氛围

## 设计支柱

### 支柱 1：每一个决策都有重量

玩家的每一个选择（学什么法术、用什么物品、走哪条路）都有明确的代价和后果。

**具体标准**：
- 学一个法术 = 牺牲其他属性点
- 用一个血瓶 = 少一次生存机会
- 走一条路 = 放弃另一条路的奖励
- 死亡 = 失去进度（不是惩罚，是学习）

**验证方法**：玩家在做决策前会犹豫吗？如果不会，决策没有重量。

### 支柱 2：信息是有价值的资源

玩家不应该被喂信息。探索、实验、失败都是获取信息的方式。

**具体标准**：
- 怪物属性不直接显示（需要玩家自己观察）
- 物品好坏需要鉴定或使用才知道
- 地牢布局是随机的，需要探索
- 法术效果需要尝试才知道

**验证方法**：玩家会因为"不知道"而感到紧张吗？如果不会，信息给得太多。

### 支柱 3：世界对玩家有反应

D1 的世界不是静态的背景。玩家的行为应该影响世界的状态。

**具体标准**：
- 杀死 Boss 后，地牢的怪物配置会变化
- 深层地牢的氛围更压抑（光照、怪物密度）
- NPC 的对话会根据玩家进度变化
- 环境细节暗示地牢的历史和故事

**验证方法**：玩家会觉得"这个世界是活的"吗？如果不会，世界太静态。

### 支柱 4：简单但深刻

不需要 100 个技能，需要 10 个有意义的技能。不需要 100 种怪物，需要 10 种有性格的怪物。

**具体标准**：
- 每个法术都有明确的使用场景
- 每种怪物都有独特的行为模式
- 每种物品都有明确的价值
- 系统之间的交互产生深度（不是系统本身复杂）

**验证方法**：玩家能用一句话说清楚每个元素的作用吗？如果不能，设计太复杂。

### 支柱 5：节奏感

D1 的节奏是：紧张 → 峰值 → 释放 → 紧张。这个循环必须保持。

**具体标准**：
- 每一层都有"安全区"和"危险区"
- Boss 战是峰值体验
- 崔斯特瑞姆是释放空间
- 探索新区域是紧张来源

**验证方法**：玩家会感到"节奏变化"吗？如果不会，节奏太平。

## D1 的独特价值（必须保留）

| 价值 | 为什么独特 | 如何深化 |
|------|-----------|---------|
| 慢节奏战斗 | 每个动作都有重量 | 让怪物行为更有深度 |
| 资源稀缺 | 每个决策都有代价 | 让资源管理更有趣 |
| 氛围优先 | 恐惧来自未知 | 让环境更有叙事性 |
| 随机地牢 | 每次游玩都不同 | 让随机性更有意义 |
| 哥特风格 | 独特的视觉语言 | 用像素做出惊艳的画面 |

## D1 的真正缺点（执行问题，不是设计问题）

| 缺点 | 问题 | 解决方向 |
|------|------|---------|
| 怪物行为简单 | 只会直线冲向玩家 | 更智能的 AI，但保持可预测性 |
| 环境互动少 | 主要是视觉背景 | 让环境成为战斗的一部分 |
| 信息不透明 | 不知道法术做什么、物品好坏 | 改善信息展示（已完成 tooltip） |
| 平衡粗糙 | 某些 build 明显更强 | 让每个 build 有独特价值 |
| 终局无聊 | 就是刷装备 | 让终局有叙事意义 |
| 部分法术无用 | Rage、Etherealize 等没人用 | 改善法术实用性 |

## 红线清单

每一个设计决策都要过这个清单：

- [ ] 它增加了决策重量，还是减少了？
- [ ] 它保持了信息稀缺，还是泄露了太多？
- [ ] 它让世界更有反应，还是更静态？
- [ ] 它保持了简单性，还是增加了复杂度？
- [ ] 它改善了节奏，还是破坏了节奏？
- [ ] 如果去掉它，游戏会变差吗？（如果不会，不要加）
- [ ] 老玩家会觉得"这就是 D1"？
- [ ] 新玩家会觉得"这和我玩过的其他游戏不一样"？

## 迭代框架

### 测试维度

| 维度 | 测试方法 | 成功标准 |
|------|---------|---------|
| 决策重量 | 玩家在做决策前是否犹豫？ | 是 |
| 信息稀缺 | 玩家是否因为"不知道"而紧张？ | 是 |
| 世界反应 | 玩家是否觉得世界是活的？ | 是 |
| 系统深度 | 玩家是否发现新的系统交互？ | 是 |
| 节奏感 | 玩家是否感到紧张→释放的节奏？ | 是 |

### 不测试的维度

- "好不好玩"（太主观）
- "死了多少次"（难度指标，不是体验指标）
- "用了多少血瓶"（资源指标，不是决策指标）

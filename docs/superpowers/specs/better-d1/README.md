## 如何使用

1. **新设计决策**：使用 [设计决策模板](design-decision-template.md) 创建文档
2. **设计评审**：使用 [设计系统综述](../2026-07-06-better-d1-design-system.md) 中的红线清单
3. **设计参考**：查阅相关领域的设计文档

## 设计决策流程

```
发现问题 → 定义问题 → 提出方案 → 支柱检查 → 红线检查 → 记录决策 → 验证效果
```

每一步都要记录在设计决策文档中。

# 消耗品系统

> 消耗品是辅助，不是核心。但辅助做好了，核心体验会更好。

## D1 的消耗品现状（事实）

| 消耗品 | 获取方式 | 使用频率 | 价值 |
|--------|---------|---------|------|
| 血瓶 | 掉落 + 购买 | 高 | 生存必需 |
| 法力瓶 | 掉落 + 购买 | 高（法师） | 施法必需 |
| 回城卷轴 | 掉落 + 购买 | 中 | 安全返回 |
| 识别卷轴 | 掉落 + 购买 | 中 | 信息获取 |
| 伤害卷轴 | 购买 | 低 | 额外伤害 |
| 符文 | 掉落 | 低 | 特殊效果 |

**核心问题**：
1. **体验繁琐**：无堆叠，背包很快满（已通过堆叠系统解决）
2. **后期无用**：血瓶/法力瓶中后期充足，决策重量消失
3. **部分消耗品无价值**：伤害卷轴、符文几乎没人用

## 设计原则

1. **消耗品是辅助**：不是游戏核心，是补充
2. **不和法术重叠**：消耗品做法术做不到的事
3. **改善体验**：堆叠、自动补充、减少繁琐
4. **和 D2 对齐**：玩家熟悉的消耗品模式

## 消耗品的独特价值

消耗品提供**法术做不到的事**：

| 消耗品 | 独特价值 | 法术能替代？ |
|--------|---------|------------|
| 高级法术卷轴 | 战士不能学的法术（需要55+魔法） | 法师能学，战士不能 |
| 回城卷轴 | 安全返回 | 法术能做，但需要学习 |
| 识别卷轴 | 物品鉴定 | 法术能做，但需要学习 |

**消耗品不是"更好的法术"，是"法术的补充"。**

## 已实现的改善

### 堆叠系统（已实现）
- 血瓶/法力瓶/卷轴可堆叠
- 堆叠数量因职业而异
- 腰带和背包都支持堆叠
- UI 显示堆叠数量

### 体验改善（已实现）
- 物品标签显示
- 地面物品比较
- 快捷使用

## 掉落设计

### 掉落的消耗品

| 消耗品 | 掉落频率 | 获取方式 |
|--------|---------|---------|
| 血瓶 | 频繁 | 掉落 + 购买 |
| 蓝瓶 | 频繁 | 掉落 + 购买 |
| 识别卷轴 | 稀有 | 掉落 + 购买 |
| 回城卷轴 | 稀有 | 掉落 + 购买 |

### 设计理由

| 设计 | 理由 |
|------|------|
| 血蓝瓶掉落 | 生存必需，不能断供 |
| 工具卷轴掉落 | 有用但不破坏平衡 |
| 回城卷轴稀有 | 决策重量——每次使用都有代价 |

## 待实现的设计

### 消耗品价值提升

**问题**：中后期血瓶/法力瓶太容易获得，决策重量消失。

**方案**：
- 减少商店库存（让购买有代价）
- 增加高级消耗品的价值（如满血瓶、满法力瓶）
- 让消耗品在 Boss 战中有战略价值

### 消耗品与职业差异化

**问题**：所有职业使用同样的消耗品。

**方案**：
- 战士：血瓶消耗更快（近战受伤更多）
- 法师：法力瓶消耗更快（施法需要法力）
- 游侠：两者均衡

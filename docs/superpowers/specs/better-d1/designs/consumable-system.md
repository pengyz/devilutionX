# 设计决策：消耗品系统

**日期**：2026-07-06
**状态**：已批准（修订版）
**决策者**：pengyz

---

## 核心认知

D1 的消耗品存在感低是设计选择，不是缺陷。消耗品是辅助，不是核心。我们不应该试图让消耗品成为核心，而应该改善使用体验。

## 消耗品的独特价值

消耗品提供**法术做不到的事**：

| 消耗品 | 独特价值 | 法术能替代？ |
|---|---|---|
| 陷阱套件 | 地面控制，敌人踩触发 | ❌ 法术没有 |
| 附魔油 | 武器临时附魔元素伤害 | ❌ 法术没有 |
| 侦察卷轴 | 显示周围敌人位置 | ❌ 法术没有 |
| 高级法术卷轴 | 战士不能学的法术（需要55+魔法） | ⚠️ 法师能学，战士不能 |

**消耗品不是"更好的法术"，是"法术的补充"。**

## 设计原则

| 原则 | 说明 |
|---|---|
| 消耗品是辅助 | 不是游戏核心，是补充 |
| 不和法术重叠 | 消耗品做法术做不到的事 |
| 改善体验 | 堆叠、自动补充、减少繁琐 |
| 和 D2 对齐 | 玩家熟悉的消耗品模式 |

## 掉落设计

### 掉落的消耗品

| 消耗品 | 掉落频率 | 获取方式 |
|---|---|---|
| 血瓶 | 频繁 | 掉落 + 购买 |
| 蓝瓶 | 频繁 | 掉落 + 购买 |
| 识别卷轴 | 稀有 | 掉落 + 购买 |
| 回城卷轴 | 稀有 | 掉落 + 购买 |

### 不掉落的消耗品

| 消耗品 | 获取方式 |
|---|---|
| 伤害卷轴 | 购买 / 制作 |
| 伤害符文 | 购买 / 制作 |
| 控制卷轴 | 购买 / 制作 |
| 附魔油 | 制作 |
| 陷阱套件 | 制作 |

### 设计理由

| 设计 | 理由 |
|---|---|
| 血蓝瓶掉落 | 生存必需，不能断供 |
| 工具卷轴掉落 | 有用但不破坏平衡 |
| 伤害卷轴不掉落 | 太容易会破坏战斗 |
| 符文不掉落 | 同上 |
| 非掉落物品购买/制作 | 有成本，不会滥用 |

## 堆叠设计

### 基础堆叠

| 消耗品类别 | 基础堆叠 |
|---|---|
| 血瓶 | 5 |
| 蓝瓶 | 5 |
| 卷轴 | 3 |
| 附魔油 | 3 |
| 陷阱套件 | 3 |
| 材料 | 10 |

### 职业差异堆叠

| 消耗品类别 | 基础 | 战士加成 | 战士实际 |
|---|---|---|---|
| 血瓶 | 5 | +3 | 8 |
| 蓝瓶 | 5 | 0 | 5 |
| 卷轴 | 3 | +1 | 4 |
| 附魔油 | 3 | +2 | 5 |
| 陷阱套件 | 3 | +2 | 5 |
| 材料 | 10 | +5 | 15 |

**设计理由**：战士强壮能背更多，符合角色设定。

## 腰带设计

| 设计点 | 说明 |
|---|---|
| 腰带格数 | 8格 |
| 堆叠 | 每格可堆叠3-5个 |
| 自动补充 | 使用后自动从背包补充 |
| 总容量 | 8格 x 5个 = 40个消耗品 |

## 经济平衡

| 调整 | 说明 |
|---|---|
| 增加金币掉落 | 补偿消耗品不掉落的损失 |
| 保持装备掉落 | 装备仍然可以卖钱 |
| 消耗品购买成本 | 适中，不会太贵 |

### 经济循环

```
打怪 → 获得金币 + 装备（可卖）
  ↓
购买消耗品（血蓝瓶、卷轴）
  ↓
制作消耗品（附魔油、陷阱）
  ↓
进入地牢
  ↓
使用消耗品
  ↓
重复
```

| 消耗品 | 战士价值 | 游侠价值 | 法师价值 |
|---|---|---|---|
| 血瓶 | **必需** | 需要 | 少量 |
| 蓝瓶 | 不需要 | 不需要 | **必需** |
| 识别卷轴 | 可选 | 可选 | 可选 |
| 回城卷轴 | 可选 | 可选 | 可选 |
| 伤害卷轴 | 可选 | 可选 | 不需要 |
| 附魔油 | 可选 | 可选 | 不需要 |
| 陷阱套件 | 可选 | 可选 | 不需要 |

## 设计支柱检查

| 支柱 | 符合？ | 说明 |
|---|---|---|
| 支柱 1：不安感 | ✅ | 消耗品稀缺，需要管理 |
| 支柱 2：稀缺 | ✅ | 伤害卷轴有成本，不会滥用 |
| 支柱 3：环境是角色 | ✅ | 材料来自怪物，环境影响获取 |
| 支柱 4：简单但深刻 | ✅ | 系统简单（掉落少），决策深刻（买什么） |
| 支柱 5：尊重玩家 | ✅ | 和 D2 对齐，玩家熟悉 |

## 红线检查

- [x] 没有让玩家觉得自己是英雄（消耗品是工具，不是神器）
- [x] 没有给玩家"赢"的感觉（消耗品解决一个问题，不是所有问题）
- [x] 没有打断沉浸感（消耗品是自然的，不是人工的）
- [x] 保持了稀缺感（消耗品有限，需要管理）
- [x] 符合世界观（消耗品是这个世界的物品）

## 关键洞察

1. **消耗品是辅助，不是核心** — D1 的核心是生存探索，不是消耗品管理
2. **不掉落伤害卷轴** — 太容易会破坏战斗
3. **堆叠+自动补充** — 改善使用体验
4. **经济平衡** — 增加金币掉落补偿消耗品不掉落

## 废弃的设计

~~原设计：消耗品是"钥匙"，不是"子弹"；所有消耗品都有独特效果。~~

**废弃理由**：过度设计，玩家可能不关心消耗品的独特效果。更简单的方案（减少掉落、改善体验）可能更好。

## 待验证

- 增加多少金币掉落合适？
- 消耗品购买成本是否合适？
- 堆叠和自动补充是否足够改善体验？

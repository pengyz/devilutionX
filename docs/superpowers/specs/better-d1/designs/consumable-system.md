# 设计决策：消耗品系统

**日期**：2026-07-06
**状态**：设计中
**决策者**：pengyz

---

## 问题

原版 D1 的消耗品系统存在几个问题：
1. 大部分消耗品价值过低（数值型，不解决问题）
2. 免费替代存在（Cain 免费鉴定）
3. 腰带操作繁琐（手动补充）
4. 玩家舍不得用（稀缺心理）

## 设计原则

### 核心理念：消耗品是"钥匙"，不是"子弹"

- **数值型消耗品**：只是加数字（+伤害、+属性）→ 设计失败
- **功能型消耗品**：解决特定问题 → 设计成功

### 设计原则

| 原则 | 说明 |
|---|---|
| 解决问题 | 每个消耗品对应一个"问题"，用对了解决问题 |
| 用错浪费 | 用错时机 = 浪费资源，用对时机 = 解决问题 |
| 补充不替代 | 补充职业短板，不替代核心能力 |
| 战术不战略 | 影响单场战斗，不影响整个游戏 |

## 消耗品分类

### 第一类：生存类（解决"我要死了"问题）

| 消耗品 | 效果 | 持续时间 | 堆叠上限 | 职业价值 |
|---|---|---|---|---|
| 生命药水 | 立即回复生命 | - | 5 | 所有职业 |
| 法力药水 | 立即回复法力 | - | 5 | 法师 > 游侠 > 战士 |
| 再生药水 | 持续回复生命 | 30秒 | 3 | 所有职业（尤其战士） |
| 法力再生药水 | 持续回复法力 | 30秒 | 3 | 法师 |

**设计理由**：
- 生命药水是必需品，所有职业都需要
- 再生药水给战士更多续航，但不是即时回复，需要提前使用
- 法力再生药水给法师更多法力管理空间

---

### 第二类：控制类（解决"怪太多/太快"问题）

| 消耗品 | 效果 | 持续时间 | 堆叠上限 | 职业价值 |
|---|---|---|---|---|
| 石化卷轴 | 石化单个敌人 | 10秒 | 3 | 战士 > 游侠 > 法师 |
| 减速卷轴 | 范围减速敌人 | 15秒 | 3 | 所有职业 |
| 恐惧卷轴 | 周围敌人逃跑 | 5秒 | 3 | 战士（被围时救命） |
| 冰冻卷轴 | 冻住单个敌人 | 8秒 | 3 | 游侠（控制远程怪） |

**设计理由**：
- 战士最需要控制（近战容易被围）
- 石化卷轴解决"物理免疫"问题（石化后可以安全输出）
- 恐惧卷轴解决"被围住"问题（战士的致命弱点）

---

### 第三类：战术类（解决"我够不到/打不到"问题）

| 消耗品 | 效果 | 持续时间 | 堆叠上限 | 职业价值 |
|---|---|---|---|---|
| 拉怪卷轴 | 把一个敌人拉到身边 | - | 3 | 战士（解决远程怪） |
| 传送卷轴 | 传送到指定方向 | - | 3 | 所有职业（撤退用） |
| 回城卷轴 | 回到崔斯特瑞姆 | - | 3 | 所有职业（安全撤退） |
| 侦测卷轴 | 显示周围敌人位置 | 30秒 | 3 | 所有职业（信息获取） |

**设计理由**：
- 拉怪卷轴给战士远程手段（不需要弓箭）
- 传送卷轴改为可控（指定方向），不再是随机
- 侦测卷轴解决"信息稀缺"问题（后期核心需求）

---

### 第四类：强化类（解决"我输出不够/防御不够"问题）

| 消耗品 | 效果 | 持续时间 | 堆叠上限 | 职业价值 |
|---|---|---|---|---|
| 魔法武器卷轴 | 武器附加魔法伤害 | 30秒 | 3 | 战士（打物理免疫） |
| 力量药水 | 大幅增加物理伤害 | 30秒 | 3 | 战士、游侠 |
| 魔法药水 | 大幅增加魔法伤害 | 30秒 | 3 | 法师 |
| 铁皮药水 | 大幅增加防御 | 30秒 | 3 | 战士（Boss战用） |
| 法力护盾卷轴 | 法力吸收伤害 | 30秒 | 3 | 法师（生存用） |

**设计理由**：
- 魔法武器卷轴解决战士"物理免疫"问题
- 力量/魔法药水是"爆发"手段，关键时刻用
- 法力护盾卷轴给法师额外生存能力

---

### 第五类：制作类（用怪物材料制作）

| 制作配方 | 材料 | 效果 | 职业价值 |
|---|---|---|---|
| 毒蛇油 | 蛇怪鳞片 x3 | 武器附加毒伤 30秒 | 战士、游侠 |
| 火焰油 | 恶魔灰烬 x3 | 武器附加火伤 30秒 | 战士、游侠 |
| 寒冷油 | 冰霜碎片 x3 | 武器附加冰伤 30秒 | 战士、游侠 |
| 陷阱套件 | 金属碎片 x5 | 放置地面陷阱 | 战士（控场） |
| 箭矢附魔 | 魔法粉尘 x3 | 制作附魔箭 10支 | 游侠 |
| 法力水晶 | 魔法精华 x5 | 回复大量法力 | 法师 |

**设计理由**：
- 制作给战士/游侠"技能"感（不是魔法，是生存技能）
- 材料来自怪物，创造正反馈循环
- 不同材料对应不同元素，鼓励探索

## 职业消耗品策略

### 战士

**核心消耗品**：
- 生命药水（续航）
- 控制卷轴（石化、恐惧——解决被围问题）
- 魔法武器卷轴（打物理免疫）
- 拉怪卷轴（解决远程怪）

**消耗品定位**：补充战士的短板（无远程、无控制、怕物理免疫）

**背包策略**：
- 腰带：4血瓶 + 2控制卷轴 + 1魔法武器卷轴 + 1拉怪卷轴
- 背包：多余血瓶 + 材料 + 备用卷轴

---

### 游侠

**核心消耗品**：
- 生命药水（生存）
- 箭矢附魔（增加伤害/效果）
- 控制卷轴（冰冻、减速——控制敌人）
- 传送卷轴（撤退）

**消耗品定位**：增强游侠的灵活性和控制能力

**背包策略**：
- 腰带：3血瓶 + 2箭矢附魔 + 2控制卷轴 + 1传送卷轴
- 背包：多余血瓶 + 材料 + 备用箭矢

---

### 法师

**核心消耗品**：
- 法力药水（续航）
- 法力护盾卷轴（生存）
- 再生药水（持续回复）
- 传送卷轴（撤退）

**消耗品定位**：解决法师的生存问题和法力管理

**背包策略**：
- 腰带：3法力药水 + 2法力护盾卷轴 + 2传送卷轴 + 1生命药水
- 背包：多余法力药水 + 材料 + 备用卷轴

## 获取方式

| 获取方式 | 说明 | 适用消耗品 |
|---|---|---|
| 怪物掉落 | 随机掉落，稀有 | 卷轴、药水 |
| 商店购买 | 用金币购买，有限供应 | 基础药水、基础卷轴 |
| 制作 | 用材料制作 | 油、陷阱、附魔箭 |
| 宝箱 | 探索获得 | 稀有卷轴、稀有药水 |

## 设计支柱检查

| 支柱 | 符合？ | 说明 |
|---|---|---|
| 支柱 1：不安感 | ✅ | 消耗品稀缺，用错时机有后果 |
| 支柱 2：稀缺 | ✅ | 消耗品有限，需要决策带什么 |
| 支柱 3：环境是角色 | ✅ | 材料来自怪物，环境影响消耗品获取 |
| 支柱 4：简单但深刻 | ✅ | 每个消耗品用途明确，但用对时机是决策 |
| 支柱 5：尊重玩家 | ✅ | 玩家需要学会什么时候用什么 |

## 红线检查

- [x] 没有让玩家觉得自己是英雄（消耗品是工具，不是神器）
- [x] 没有给玩家"赢"的感觉（消耗品解决一个问题，不是解决所有问题）
- [x] 没有打断沉浸感（消耗品是自然的，不是人工的）
- [x] 保持了稀缺感（消耗品有限，需要管理）
- [x] 符合世界观（消耗品是这个世界的物品，不是外来物）

## 待验证

- 消耗品的数值平衡（效果强度、持续时间、冷却时间）
- 制作系统的复杂度（是否太繁琐？）
- 材料掉落的稀有度（是否太容易/太难获得？）

# 设计决策：法术等级系统

**日期**：2026-07-06
**状态**：已批准
**决策者**：pengyz

---

## 问题

原版 D1 的法术系统存在几个问题：
1. 职业边界模糊——战士能学 Town Portal 等高级法术
2. 消耗品价值低——能学法术为什么要用卷轴？
3. 没有法术等级概念——所有法术平等，没有层次感
4. 魔法需求不合理——低级法术需求太高，战士学不了

## 方案

### 核心设计：法术等级 + 魔法需求

借鉴 DND 的法术等级系统，用**硬限制（法术等级）** + **软限制（魔法需求）** 双系统。

### 法术等级定义

| 等级 | 说明 | 定位 |
|---|---|---|
| 0级（戏法） | 基础法术 | 通用技能，所有人都能学 |
| 1级 | 基础法术 | 游侠能学，战士需要卷轴 |
| 2级 | 进阶法术 | 法师能学，其他需要卷轴 |
| 3级 | 高级法术 | 法师能学，其他需要卷轴 |
| 4级 | 终极法术 | 法师能学，其他需要卷轴 |

### 职业学习限制

| 职业 | 能学法术等级 | 说明 |
|---|---|---|
| 战士 | 0级 | 只能学戏法，高级法术靠卷轴 |
| 游侠 | 0-1级 | 能学基础+中级法术 |
| 法师 | 0-4级 | 能学所有法术 |

### 各职业法术学习情况

#### 战士

| 阶段 | 魔法值 | 能学法术 | 需要投资？ |
|---|---|---|---|
| 1级（起始） | ~10 | 0级（Firebolt, Healing等） | 不需要 |
| 15级 | ~24 | 0级 | 不需要 |

**战士的法术来源**：
- 0级法术：自动学会（魔法需求10，战士起始就有）
- 1级+法术：需要消耗品卷轴

#### 游侠

| 阶段 | 魔法值 | 能学法术 | 需要投资？ |
|---|---|---|---|
| 1级（起始） | ~15 | 0级 | 不需要 |
| 10级 | ~25 | 0-1级（部分） | 需要投资 |
| 15级 | ~35 | 0-1级 | 需要投资 |

**游侠的法术来源**：
- 0级法术：自动学会
- 1级法术：需要投资魔法属性
- 2级+法术：需要消耗品卷轴

#### 法师

| 阶段 | 魔法值 | 能学法术 | 需要投资？ |
|---|---|---|---|
| 1级（起始） | ~35 | 0-1级 | 不需要 |
| 10级 | ~60 | 0-3级 | 需要投资 |
| 15级 | ~85 | 0-4级 | 需要投资 |

**法师的法术来源**：
- 0-4级法术：学习（需要投资魔法属性）
- 消耗品：补充手段（省法力）

## 设计支柱检查

| 支柱 | 符合？ | 说明 |
|---|---|---|
| 支柱 1：不安感 | ✅ | 高级法术稀缺，使用有代价 |
| 支柱 2：稀缺 | ✅ | 高级法术对非法师稀缺 |
| 支柱 3：环境是角色 | ✅ | 法术获取影响探索策略 |
| 支柱 4：简单但深刻 | ✅ | 系统简单（等级+需求），决策深刻 |
| 支柱 5：尊重玩家 | ✅ | 边界清晰，代价明确 |

## 红线检查

- [x] 没有让玩家觉得自己是英雄（战士不能成为法师）
- [x] 没有给玩家"赢"的感觉（学法术需要代价）
- [x] 没有打断沉浸感（法术等级符合世界观）
- [x] 保持了稀缺感（高级法术稀缺）
- [x] 符合世界观（法术有层次，不是所有魔法都平等）

## 关键洞察

1. **双系统设计** — 法术等级（硬限制）+ 魔法需求（软限制）
2. **0级法术通用** — 降低需求到10，所有人都能学
3. **职业边界清晰** — 法术等级决定上限，不能突破
4. **消耗品价值高** — 战士/游侠需要卷轴获取高级法术
5. **属性投资有意义** — 学法术需要牺牲其他属性

## 与其他系统的关系

| 系统 | 关系 |
|---|---|
| 资源系统 | 法力稀缺影响施法次数 |
| 消耗品系统 | 卷轴是获取高级法术的途径 |
| 装备系统 | 法杖提供+法术等级等属性 |
| 充能法杖 | 稀有，提供额外法术来源 |

# 设计决策：法术系统

**日期**：2026-07-06
**状态**：已批准（修订版）
**决策者**：pengyz

---

## 核心认知

D1 的法术系统比我们最初认知的更完备。它通过**属性上限**实现了隐式的职业边界，不需要额外的法术等级系统。

## D1 的设计：硬限制 + 软限制

### 硬限制：属性上限

| 职业 | 力量上限 | 魔法上限 | 敏捷上限 | 体力上限 |
|---|---|---|---|---|
| 战士 | 250 | **50** | 60 | 100 |
| 游侠 | 55 | **70** | 250 | 80 |
| 法师 | 45 | **250** | 85 | 80 |

**关键发现**：战士魔法上限只有50，即使把所有属性点都加到魔法，也只能到50。

**战士的实际情况**：
- 起始魔法10，上限50
- 可投资40点到魔法
- 能学大部分0-1级法术
- 学2级法术需要牺牲大量其他属性
- 学不了3-4级法术

**游侠的实际情况**：
- 起始魔法15，上限70
- 可投资55点到魔法
- 能学大部分0-2级法术
- 学3级法术需要牺牲大量其他属性
- 学不了4级法术

**法师的实际情况**：
- 起始魔法35，上限250
- 可投资215点到魔法
- 能学所有法术

## 设计优势

| 优势 | 说明 |
|---|---|
| 隐式边界 | 通过属性上限自然限制，不需要额外系统 |
| 保持灵活性 | 战士能学1级法术，但需要投资 |
| 有代价的选择 | 学法术 = 牺牲其他属性 |
| 符合 D1 特色 | 模糊边界，自由加点 |

## 问题：UX 不清晰

| 问题 | 说明 |
|---|---|
| 玩家不知道属性上限 | 不知道战士魔法只能到50 |
| 玩家不知道法术需求 | 不知道 Town Portal 需要20魔法 |
| 玩家不知道能学什么 | 要到加点时才发现学不了 |

## 解决方案：改善 UX，不加新系统

### 角色界面改善

**当前显示**：
```
魔法：10
```

**改善后显示**：
```
魔法：10/50（上限50）
```

### 法术书改善

**当前显示**：
```
Town Portal
需要20魔法
```

**改善后显示**：
```
Town Portal
需要20魔法（当前10，还需10）
状态：可学（需投资10点魔法）
```

或

**改善后显示**：
```
Fireball
需要55魔法（当前10，还需45）
状态：无法学习（超过上限50）
```

## 废弃的设计：法术等级系统

~~原设计：借鉴 DND 的法术等级系统（0-4级），用硬限制替代软限制。~~

**废弃理由**：
1. D1 的属性上限已经是硬限制
2. 法术等级系统增加了不必要的复杂度
3. 失去了 D1 的模糊边界特色
4. 解决的问题（UX不清晰）可以通过改善显示解决

## 设计决策

| 决策 | 说明 |
|---|---|
| 不加法术等级系统 | D1 的属性上限已经足够 |
| 改善 UX | 让玩家清楚知道限制 |
| 保持 D1 特色 | 模糊边界、自由加点 |
| 保持原版魔法需求 | 不调整，保持原版平衡 |

## 与其他系统的关系

| 系统 | 关系 |
|---|---|
| 资源系统 | 法力稀缺影响施法次数 |
| 消耗品系统 | 不能学的法术需要卷轴 |
| 装备系统 | 法杖提供+魔法等属性 |
| 充能法杖 | 受魔法需求限制 |

## 待验证

- 0级法术需求10是否太低（战士自动获得）？
- UX 改善是否足够清晰？
- 消耗品价值是否足够（战士需要卷轴获取高级法术）？

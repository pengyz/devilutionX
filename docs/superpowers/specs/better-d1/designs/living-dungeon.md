# 活着的地下城

> 灵感来源于空洞骑士的遗忘十字路→被感染的十字路。随着游戏进程，整个世界发生视觉、叙事和氛围上的变化，让玩家感受到世界在恶化。

## 设计原则

| 原则 | 说明 |
|------|------|
| 渐进 | 变化是逐渐的，不是突然的 |
| 有意义 | 变化有叙事意义 |
| 不破坏 | 变化不会让游戏无法进行 |
| 可察觉 | 玩家能注意到变化 |
| 有后果 | 变化影响游戏体验 |

## 系统组成

| 组成部分 | 说明 |
|---------|------|
| 崔斯特瑞姆变化 | NPC 对话、氛围 |
| 地牢变化 | 怪物配置、环境 |
| NPC 对话变化 | 状态驱动的对话 |
| 世界事件 | 触发条件、变化内容 |

## NPC 对话变化（可实现，无需新美术资源）

### 对话状态系统

| 状态 | 触发条件 | NPC 反应 |

| 正常 | 游戏开始 | 正常对话 |
| 警觉 | 击败骷髅王 | 开始担忧 |

| 恐惧 | 进入地狱 | 非常害怕 |
| 绝望 | 接近 Diablo | 几乎放弃 |

## 地牢变化

### 视觉变化（需要新美术资源，标注为待实现）

| 层 | 视觉变化 | 氛围 |
|----|---------|------|
| 教堂 | 腐化开始（裂痕、血迹） | 正常偏暗 |
| 地下墓穴 | 腐化加深（更多尸体、更暗） | 阴森 |
| 洞穴 | 岩浆渗透（地面岩浆、空气扭曲） | 炎热 |
| 地狱 | 完全腐化（火焰、恶魔痕迹） | 恐怖 |

### 怪物变化（已部分实现）

| 层 | 怪物变化 |
|----|---------|
| 教堂 | 普通怪物 |
| 地下墓穴 | 更强怪物 |
| 洞穴 | 更危险怪物 |
| 地狱 | 极危险怪物 |

### 环境变化（已实现光照压制）

| 层 | 环境变化 |
|----|---------|
| 教堂 | 正常 |
| 地下墓穴 | 更暗、更多陷阱 |
| 洞穴 | 火焰、毒液、岩浆 |
| 地狱 | 极暗、火焰遍布 |

## 世界事件

### 事件列表

| 事件 | 触发条件 | 效果 |
|------|---------|------|
| 裂痕出现 | 击败骷髅王 | 崔斯特瑞姆出现裂痕 |
| 怪物入侵 | 进入地狱 | 怪物出现在镇外 |
| 黑暗降临 | 接近 Diablo | 整体变暗 |
| 腐化蔓延 | 深度增加 | 地牢更腐化 |
| 岩浆渗透 | 进入洞穴 | 地面出现岩浆 |

### 事件效果

| 事件 | 视觉效果 | 叙事效果 | 游戏效果 |
|------|---------|---------|---------|
| 裂痕出现 | 地面裂痕 | NPC 担忧 | 无 |
| 怪物入侵 | 怪物痕迹 | NPC 害怕 | 无 |
| 黑暗降临 | 光照减少 | NPC 绝望 | 影响视野 |
| 腐化蔓延 | 腐化物体 | NPC 评论 | 无 |
| 岩浆渗透 | 岩浆物体 | NPC 警告 | 地面危险 |

# 设计决策：活着的地下城

**日期**：2026-07-06
**状态**：已批准
**决策者**：pengyz

---

## 核心认知

灵感来源于空洞骑士的遗忘十字路→被感染的十字路。随着游戏进程，整个世界（崔斯特瑞姆和地牢）会发生视觉、叙事和氛围上的变化，让玩家感受到世界在恶化。

## 设计原则

| 原则 | 说明 |
|---|---|
| 渐进 | 变化是逐渐的，不是突然的 |
| 有意义 | 变化有叙事意义 |
| 不破坏 | 变化不会让游戏无法进行 |
| 可察觉 | 玩家能注意到变化 |
| 有后果 | 变化影响游戏体验 |

## 系统组成

| 组成部分 | 说明 |
|---|---|
| 崔斯特瑞姆变化 | 视觉、NPC、氛围 |
| 地牢变化 | 视觉、怪物、环境 |
| NPC对话变化 | 新对话、评论、反应 |
| 世界事件 | 触发条件、变化内容 |

## 崔斯特瑞姆变化

### 视觉变化

| 阶段 | 触发条件 | 视觉效果 | 氛围 |
|---|---|---|---|
| 游戏开始 | 无 | 正常小镇 | 安全 |
| 阶段1 | 击败骷髅王 | 地面裂痕 | 微妙不安 |
| 阶段2 | 进入洞穴 | 变暗、血迹 | 紧张 |
| 阶段3 | 进入地狱 | 黑暗笼罩 | 恐惧 |
| 阶段4 | 接近Diablo | 完全黑暗 | 绝望 |

|---|---|---|---|

| Pepin | "我看到更多受伤的人..." | "黑暗正在蔓延..." | "我治不好这么多人" |
| Cain | "邪恶正在觉醒..." | "Diablo快要醒了" | "我们必须阻止他" |
| Farnham | "我看到怪物在镇外..." | "我们都要死了" | "我喝不下去了" |
| Adria | "黑暗力量在增长..." | "我能感受到他的存在" | "准备好面对他" |
| Gillian | "我害怕..." | "我不敢出门了" | "请救救我们" |

### 实现方式

| 实现 | 说明 |
|---|---|
| 视觉变化 | 物体放置（裂痕、血迹）、光照变化 |
| NPC反应 | 状态驱动的对话系统 |
| 触发条件 | 击败Boss、进入新层 |

## 地牢变化

### 视觉变化

| 层 | 视觉变化 | 氛围 |
|---|---|---|
| 教堂 | 腐化开始（裂痕、血迹） | 正常偏暗 |
| 地下墓穴 | 腐化加深（更多尸体、更暗） | 阴森 |
| 洞穴 | 岩浆渗透（地面岩浆、空气扭曲） | 炎热 |
| 地狱 | 完全腐化（火焰、恶魔痕迹） | 恐怖 |

### 怪物变化

| 层 | 怪物变化 |
|---|---|
| 教堂 | 普通怪物 |
| 地下墓穴 | 更强怪物 |
| 洞穴 | 更危险怪物 |
| 地狱 | 极危险怪物 |

### 环境变化

| 层 | 环境变化 |
|---|---|
| 教堂 | 正常 |
| 地下墓穴 | 更暗、更多陷阱 |
| 洞穴 | 火焰、毒液、岩浆 |
| 地狱 | 极暗、火焰遍布 |

### 实现方式

| 实现 | 说明 |
|---|---|
| 视觉变化 | 瓦片替换、物体放置、调色板交换 |
| 怪物变化 | 怪物类型和属性随深度变化 |
| 环境变化 | 光照压制、地面危险物 |
| 触发条件 | 进入新层 |

## 设计支柱检查

| 支柱 | 符合？ | 说明 |
|---|---|---|
| 支柱 1：不安感 | ✅ | 世界在恶化，增加紧张感 |
| 支柱 3：环境是角色 | ✅ | 环境是叙事的一部分 |
| 支柱 4：简单但深刻 | ✅ | 系统简单（触发+效果），叙事深刻 |
| 支柱 5：尊重玩家 | ✅ | 变化有逻辑，不是随机 |

## 红线检查

- [x] 没有让玩家觉得自己是英雄（世界在恶化）
- [x] 没有给玩家"赢"的感觉（世界在崩溃）
- [x] 没有打断沉浸感（变化是自然的）
- [x] 保持了稀缺感（世界在恶化，资源更稀缺）
- [x] 符合世界观（黑暗正在蔓延）

## 关键洞察

1. **渐进变化** — 变化是逐渐的，不是突然的
2. **多维度变化** — 视觉、对话、氛围、游戏效果
3. **状态驱动** — 变化由游戏进度触发
4. **叙事意义** — 变化讲述故事
5. **玩家感受** — 玩家感受到世界在恶化

## 待验证

- 变化节奏是否合适？
- NPC对话变化是否自然？
- 视觉变化是否可察觉？
- 变化是否影响游戏性能？

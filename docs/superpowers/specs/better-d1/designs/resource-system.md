# 设计决策：资源系统

**日期**：2026-07-06
**状态**：已批准
**决策者**：pengyz

---

## 问题

D1 的资源系统存在几个问题：
1. 稀缺性是递减的——后期资源充足，稀缺感消失
2. 不同职业的体验同质化——战士和法师面对同样的资源问题
3. 战士缺乏决策深度——"无脑砍砍砍"导致体验无聊

## 方案

### 核心原则

1. **稀缺性贯穿始终，但稀缺的内容变化**
2. **每个职业有不同的稀缺资源和难度曲线**
3. **决策深度 ≠ 体验深度——战士决策少但每个决策很重**

### 资源稀缺曲线

| 阶段 | 物理资源 | 策略资源 | 信息资源 |
|---|---|---|---|
| 前期 | 稀缺（血瓶少） | 充裕 | 充裕 |
| 中期 | 中等 | 稀缺 | 中等 |
| 后期 | 充裕 | 稀缺 | 稀缺 |

### 职业差异化设计

#### 法师

**稀缺资源**：法力（主）、血瓶（次）

**难度曲线**：
- 前期：难（法力少、脆皮、技能有限）
- 中期：中（法力增加、技能更多）
- 后期：易（强力 AoE、远程安全）

**体验感受**："我在操控战场"

**决策深度**：高——用什么法术、什么时候用、法力管理

**优势**：AoE 清怪、远程安全
**劣势**：脆皮、怕 Boss

---

#### 游侠

**稀缺资源**：箭矢（主）、位置（次）

**难度曲线**：
- 前期：易（远程、安全、输出不错）
- 中期：中（位置变得更重要）
- 后期：中（怪物变强、输出相对不足）

**体验感受**："我在寻找机会"

**决策深度**：中——目标选择、走位、箭矢管理

**优势**：远程、灵活
**劣势**：输出一般、怕近身

---

#### 战士

**稀缺资源**：血瓶（前期）、拉怪机会（后期）、高级法术（需要卷轴）

**难度曲线**：
- 前期：易（血厚、简单）
- 中期：中（需要管理拉怪节奏）
- 后期：难（怪物多、拉怪决策重）

**体验感受**："我在刀尖上行走"

**决策深度**：中（能学低级法术，高级法术需要卷轴）

**优势**：高 DPS、能抗 Boss
**劣势**：怕怪群、需要拉怪节奏、高级法术需要卷轴

**战士的独特设计**：
- 战士有持续高输出
- 耐心引怪可以快速解决单个怪物
- Boss 战对战士更简单（能抗住 Boss 攻击）
- 后期的主要挑战是怪物布局分析和拉怪策略
- 战士能学低级法术（需要投资魔法），高级法术需要消耗品卷轴

## 设计支柱检查

| 支柱 | 符合？ | 说明 |
|---|---|---|
| 支柱 1：不安感 | ✅ | 每个职业在不同阶段都有不安来源 |
| 支柱 2：稀缺 | ✅ | 稀缺贯穿始终，形式因职业而异 |
| 支柱 3：环境是角色 | ✅ | 怪物布局影响战士的拉怪决策 |
| 支柱 4：简单但深刻 | ✅ | 系统简单（同一套资源），体验深刻（不同职业不同感受） |
| 支柱 5：尊重玩家 | ✅ | 玩家需要学习职业特性，而不是被告诉 |

## 红线检查

- [x] 没有让玩家觉得自己是英雄（每个职业都有弱点）
- [x] 没有给玩家"赢"的感觉（每个阶段都有挑战）
- [x] 没有打断沉浸感（资源系统是自然的，不是人工的）
- [x] 保持了稀缺感（稀缺贯穿始终）
- [x] 符合世界观（资源稀缺是 D1 的核心设定）

## 关键洞察

1. **稀缺的形式因职业而异，但稀缺的程度应该相当** — 每个职业都有自己的"痛点"
2. **决策深度 ≠ 体验深度** — 战士决策少但每个决策很重，法师决策多但相对安全
3. **难度曲线应该不同** — 法师前期难后期易，战士前期易后期难
4. **不对称性创造多样性** — 不同职业有不同的优势和劣势，鼓励玩家尝试不同职业

## 待验证

- 战士后期的"拉怪机会"稀缺是否足够有趣？
- 法师前期的难度是否会让玩家望而却步？
- 游侠的体验是否足够独特（不是法师和战士的中间态）？

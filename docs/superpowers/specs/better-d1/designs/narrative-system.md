# 叙事系统

> D1 的叙事不是通过文本讲述的，是通过环境暗示的。

## D1 的叙事现状（事实）

D1 的叙事是**分布式**的，通过多个渠道交付：

| 渠道 | 例子 | 特点 |
|------|------|------|
| NPC 对话 | Ogden 讲骷髅王的故事 | 状态驱动，进度相关 |
| 地牢书籍 | 盲人之书、血之书 | 背景故事 |
| 怪物对话 | Gharbad 的 4 阶段对话 | 遭遇时触发 |
| 环境细节 | 屠夫房间的血迹 | 视觉暗示 |
| 过场动画 | Lazarus 揭示、结局 | 关键剧情节点 |

**优势**：玩家自己拼凑故事，不是被告知。
**劣势**：大部分房间没有故事，后期叙事薄弱。

## 设计方向

### 环境叙事（可实现）

利用现有资源讲故事，不需要新美术：

| 环境元素 | 叙事效果 |
|---------|---------|
| 血迹 + 尸体 | "这里发生过战斗" |
| 空血瓶 + 散落金币 | "有人来过但失败了" |
| 宗教物品 + 蜡烛 | "有人在这里崇拜什么" |
| 刑具 + 骷髅 | "这里有人被折磨" |
| 书架 + 烧瓶 | "有人在这里研究魔法" |

**原则**：环境叙事是可选的，不是强迫的。玩家可以选择忽略。

### NPC 评论（已部分实现）

NPC 根据玩家状态给出评论：
- 装备变化："那把剑看起来很锋利"
- 进度变化："你去过洞穴了？小心那里"
- 健康状态："你看起来很疲惫"

**原则**：评论有信息量，不是废话。不打断玩家流程。

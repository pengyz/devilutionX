# 设计决策：叙事系统

**日期**：2026-07-06
**状态**：已批准
**决策者**：pengyz

---

## 核心认知

D1 的叙事系统比我们最初认知的更完备。它通过分布式、非线性叙事让玩家从多个来源拼凑故事。我们不需要重新设计叙事系统，只需要增强环境叙事和房间装饰。

## D1 叙事系统现状

### 叙事架构

```
崔斯特瑞姆NPC（中枢）
    ↓ 任务钩子、评论、背景
地牢探索（辐射）
    ↓ 书籍、怪物对话、环境细节
玩家拼凑故事
```

### 叙事交付渠道

| 渠道 | 说明 | 例子 |
|---|---|---|
| NPC对话 | 任务钩子、评论 | Ogden讲骷髅王的故事 |
| 地牢书籍 | 背景故事、任务触发 | 盲人之书、血之书 |
| 怪物对话 | 遭遇前的对话 | Gharbad的4阶段对话 |
| 环境细节 | 视觉叙事 | 屠夫房间的血迹 |
| 英雄台词 | 发现、战斗 | "我从没来过这里" |
| 过场动画 | 关键剧情 | Lazarus揭示、结局 |

### D1 叙事的优势

| 优势 | 说明 |
|---|---|
| 非线性叙事 | 玩家自己拼凑故事 |
| 多渠道交付 | 不依赖单一来源 |
| 状态驱动对话 | NPC知道玩家的进度 |
| 职业特定文本 | 不同职业读同一本书有不同的声音 |
| 高重玩性 | 随机任务、随机对话 |

### D1 叙事的劣势

| 劣势 | 说明 |
|---|---|
| 环境叙事有限 | 只有任务房间有细节 |
| 房间内部单调 | 非任务房间缺乏故事 |
| 后期叙事薄弱 | 地狱层叙事较少 |

## 设计原则

| 原则 | 说明 |
|---|---|
| 克制是美德 | 不是加更多，是加得更好 |
| 氛围优先 | 叙事服务于氛围，不是反过来 |
| 可选性 | 叙事是可选的，不是强迫的 |
| 质量>数量 | 少量高质量 > 大量低质量 |

## 优化方向

### 1. 房间装饰系统

**装饰类型**

| 类型 | 说明 | 叙事作用 |
|---|---|---|
| 被摧毁的营地 | 帐篷、篝火残骸、散落物品 | 告诉玩家"有人来过，但失败了" |
| 被遗弃的补给 | 空血瓶、破武器、散落金币 | 告诉玩家"有人在这里战斗过" |
| 血迹和尸体 | 地板上的血迹、倒下的冒险者 | 告诉玩家"这里很危险" |
| 破碎的家具 | 翻倒的桌子、破碎的椅子 | 告诉玩家"这里发生过暴力" |
| 宗教物品 | 蜡烛、祭坛、神像 | 告诉玩家"这里有人崇拜什么" |
| 实验器材 | 烧瓶、书籍、魔法阵 | 告诉玩家"有人在这里研究魔法" |

**装饰放置规则**

| 规则 | 说明 |
|---|---|
| 房间类型匹配 | 教堂放宗教物品，洞穴放自然物品 |
| 随机化 | 不是每个房间都有装饰（10-20%房间） |
| 不影响游戏性 | 装饰只是视觉，不影响战斗 |

### 2. 环境危险物叙事

**危险物的故事背景**

| 危险物 | 可能的故事背景 |
|---|---|
| 地面火焰 | 恶魔仪式的残留、战斗中的火焰法术 |
| 毒液池 | 炼金实验的泄漏、怪物的排泄物 |
| 冰面 | 魔法实验的失败、自然寒冷 |
| 尖刺 | 陷阱、怪物的巢穴防御 |
| 岩浆 | 地狱的渗透、自然地质 |

**危险物的视觉叙事**

| 视觉元素 | 说明 |
|---|---|
| 周围的痕迹 | 火焰周围有烧焦的痕迹 |
| 散落的物品 | 毒液池边有破碎的瓶子 |
| 怪物的尸体 | 尖刺上有被刺穿的怪物 |
| 环境的变化 | 岩浆周围的岩石被烤红 |

### 3. NPC评论深化

**评论类型**

| 类型 | 触发条件 | 例子 |
|---|---|---|
| 装备评论 | 玩家有更好的装备 | "那把剑看起来很锋利" |
| 进度评论 | 玩家到达新的层 | "你去过洞穴了？小心那里" |
| 健康评论 | 玩家血量低 | "你看起来很疲惫" |
| 任务评论 | 任务进度变化 | "你找到了那个东西吗？" |
| 背景评论 | 随机触发 | "我听说地牢里有..." |

**评论的叙事作用**

| 作用 | 说明 |
|---|---|
| 世界构建 | 让玩家了解这个世界 |
| 情感连接 | 让玩家关心NPC |
| 提示信息 | 暗示危险或机会 |
| 氛围营造 | 增强紧张感或安全感 |

**评论克制原则**

| 原则 | 说明 |
|---|---|
| 不是每次对话都评论 | 只有特殊情况下评论 |
| 评论有信息量 | 不是废话 |
| 不打断流程 | 不强迫玩家听 |

### 4. 地牢书籍深化

**书籍类型**

| 类型 | 说明 | 叙事作用 |
|---|---|---|
| 历史书籍 | 讲述地牢的历史 | 世界构建 |
| 日记书籍 | 冒险者的日记 | 个人故事 |
| 警告书籍 | 警告危险 | 提示信息 |
| lore书籍 | Diablo宇宙的lore | 背景知识 |
| 任务书籍 | 触发或推进任务 | 游戏进展 |

**书籍放置规则**

| 规则 | 说明 |
|---|---|
| 每层最多2-3本 | 不是每层都有 |
| 位置有意义 | 放在故事相关的地方 |
| 内容和层相关 | 教堂层放教堂历史，洞穴层放洞穴故事 |
| 可选阅读 | 不读也不影响游戏 |

### 5. 怪物对话深化

**对话类型**

| 类型 | 说明 | 例子 |
|---|---|---|
| 威胁对话 | 怪物威胁玩家 | "你来这里找死吗？" |
| 背景对话 | 怪物透露背景 | "我曾经是个人类..." |
| 警告对话 | 怪物警告玩家 | "你不该来这里" |
| 求饶对话 | 怪物求饶 | "放过我，我告诉你宝藏在哪" |

**对话触发条件**

| 条件 | 说明 |
|---|---|
| 首次遭遇 | 玩家第一次看到怪物 |
| 血量低 | 怪物血量低于某个阈值 |
| 特定位置 | 在特定地方触发 |
| 特定时间 | 在特定时间触发 |

**对话克制原则**

| 原则 | 说明 |
|---|---|
| 只有独特怪物有对话 | 普通怪物没有 |
| 对话有信息量 | 不是废话 |
| 对话有节奏 | 不打断战斗 |

## 资源需求分析

### 已有的物体类型

| 类型 | 物体 | 说明 |
|---|---|---|
| 光源 | OBJ_L1LIGHT, OBJ_SKFIRE, OBJ_CANDLE1-2, OBJ_TORCHL/R, OBJ_STORYCANDLE | 各种火把、蜡烛 |
| 容器 | OBJ_CHEST1-3, OBJ_TCHEST1-3, OBJ_BARREL, OBJ_POD, OBJ_URN | 宝箱、桶、罐子 |
| 家具 | OBJ_BOOKSHELF, OBJ_WEAPRACK, OBJ_ARMORSTAND, OBJ_WEAPONRACK | 书架、武器架、盔甲架 |
| 宗教 | OBJ_BANNERL/M/R, OBJ_BCROSS, OBJ_ANGEL, OBJ_PEDESTAL, OBJ_ALTBOY | 旗帜、十字架、祭坛 |
| 刑具 | OBJ_TORTURE1-5, OBJ_NUDEW2R, OBJ_TNUDEM1-4, OBJ_TNUDEW1-3, OBJ_DECAP | 刑具、尸体 |
| 骷髅 | OBJ_SKPILE, OBJ_SKSTICK1-5, OBJ_CRUX1-3 | 骷髅堆、十字架 |
| 特殊 | OBJ_SARC, OBJ_FLAMEHOLE, OBJ_WATER, OBJ_BLOODFTN, OBJ_GOATSHRINE, OBJ_CAULDRON | 石棺、火焰、水、血泉 |

### 资源需求评估

| 需求 | 已有资源 | 够用？ |
|---|---|---|
| 被摧毁的营地 | 火把、桶、箱子 | ✅ 够用 |
| 被遗弃的补给 | 桶、箱子、武器架 | ✅ 够用 |
| 血迹和尸体 | OBJ_BLOODFTN、刑具、尸体 | ✅ 够用 |
| 破碎的家具 | 书架、武器架 | ⚠️ 部分够用 |
| 宗教物品 | 祭坛、十字架、旗帜 | ✅ 够用 |
| 实验器材 | OBJ_CAULDRON、OBJ_MCIRCLE | ⚠️ 部分够用 |
| 地面火焰 | OBJ_FLAMEHOLE | ✅ 够用 |
| 水/毒液 | OBJ_WATER | ✅ 够用 |

**结论**：大部分需求可以用已有资源满足。可能需要新增的：
- 破碎家具的变体
- 实验器材的变体
- 新的装饰物体（如果需要）

## 实现策略

| 策略 | 说明 |
|---|---|
| 复用已有物体 | 用现有物体组合成新场景 |
| 物体组合 | 多个物体组合成一个"场景" |
| 随机放置 | 在房间内随机放置装饰 |
| 不需要新资源 | 大部分用已有资源 |

## 设计支柱检查

| 支柱 | 符合？ | 说明 |
|---|---|---|
| 支柱 1：不安感 | ✅ | 环境叙事增强紧张感 |
| 支柱 3：环境是角色 | ✅ | 环境讲述故事 |
| 支柱 4：简单但深刻 | ✅ | 系统简单（物体放置），叙事深刻 |
| 支柱 5：尊重玩家 | ✅ | 叙事是可选的，不是强迫的 |

## 红线检查

- [x] 没有让玩家觉得自己是英雄（环境叙事展示失败者）
- [x] 没有给玩家"赢"的感觉（环境叙事展示危险）
- [x] 没有打断沉浸感（叙事是自然的，不是强迫的）
- [x] 保持了稀缺感（叙事是可选的，不是必须的）
- [x] 符合世界观（叙事符合D1的黑暗氛围）

## 关键洞察

1. **D1叙事系统已完备** — 分布式、非线性、多渠道
2. **环境叙事是优化方向** — 非任务房间缺乏故事
3. **克制是美德** — 不是加更多，是加得更好
4. **已有资源够用** — 大部分用现有物体组合
5. **可选性重要** — 叙事是可选的，不是强迫的

## 与其他系统的关系

| 系统 | 关系 |
|---|---|
| 关卡设计 | 房间装饰是关卡设计的一部分 |
| 地牢生成 | 装饰在生成后放置 |
| 任务系统 | 部分装饰和任务相关 |
| 环境系统 | 环境危险物有叙事背景 |

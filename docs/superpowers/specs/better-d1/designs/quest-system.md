# 设计决策：任务系统

**日期**：2026-07-06
**状态**：已批准
**决策者**：pengyz

---

## 核心认知

D1 的任务系统已经相当成熟，但部分任务比较肤浅（纯杀怪），任务奖励不够有意义。我们需要优化现有任务，增加任务深度，并设计有意义的奖励。

## D1 任务系统现状

### 任务分布

| 层 | 任务 | 数量 |
|---|---|---|
| 教堂（1-4层） | Butcher, Poisoned Water, Ogden's Sign, Gharbad, Skeleton King | 5 |
| 地下墓穴（5-8层） | Magic Rock, Halls of the Blind, Chamber of Bone, Valor, Black Mushroom, Zhar | 6 |
| 洞穴（9-12层） | Anvil of Fury, Warlord of Blood | 2 |
| 地狱（13-16层） | Lachdanan, Lazarus, Diablo | 3 |

### 问题

| 问题 | 说明 |
|---|---|
| 分布不均 | 墓穴6个，洞穴只有2个 |
| 后期薄弱 | 洞穴和地狱任务较少 |
| 部分任务肤浅 | Butcher、Skeleton King等纯杀怪 |
| 奖励不够有意义 | 奖励多为随机装备 |

## 设计原则

| 原则 | 说明 |
|---|---|
| 融入叙事 | 任务是故事的一部分 |
| 均匀分布 | 每层2-3个任务 |
| 有意义的选择 | 选择有后果，没有绝对对错 |
| 有意义的奖励 | 奖励改变游戏体验 |
| 克制 | 不是加更多，是加得更好 |

## 新增任务

### 洞穴层（9-12层）— 增加3个任务

| 任务 | 故事 | 类型 | 奖励 |
|---|---|---|---|
| 失落的矿工 | 矿工失踪，玩家需要找到他们 | 探索 | 矿工的遗物 |
| 恶魔契约 | 恶魔提出交易 | 选择 | 恶魔的礼物（有代价） |
| 被困的灵魂 | 灵魂被困在洞穴里 | 解救 | 灵魂的祝福 |

### 地狱层（13-16层）— 增加2个任务

| 任务 | 故事 | 类型 | 奖励 |
|---|---|---|---|
| 堕落骑士 | 骑士堕落了，玩家需要决定他的命运 | 选择 | 骑士的装备 |
| 地狱之门 | 地狱之门需要关闭 | 探索 | 关闭门的奖励 |

## 纯杀怪任务优化

### Butcher（屠夫）

| 要素 | 原版 | 优化后 |
|---|---|---|
| 对话 | 无 | 屠夫有对话（"你来这里找死吗？"） |
| 环境 | 血迹 | 更多叙事细节（尸体、刑具、日记） |
| 选择 | 无 | 可以尝试逃跑（屠夫会追击） |
| 后果 | 无 | 屠夫死亡后，镇民有评论 |

### Skeleton King（骷髅王）

| 要素 | 原版 | 优化后 |
|---|---|---|
| 对话 | 无 | 骷髅王有对话（关于他的疯狂） |
| 环境 | 宝座 | 更多叙事细节（破碎的王冠、腐化的徽章） |
| 选择 | 无 | 可以尝试说理（失败，但增加深度） |
| 后果 | 无 | 骷髅王死亡后，镇民有评论 |

### Warlord of Blood（战争领主）

| 要素 | 原版 | 优化后 |
|---|---|---|
| 对话 | 有9段对话 | 保留并增强对话 |
| 环境 | 房间 | 更多叙事细节（武器架、盔甲、血迹） |
| 选择 | 无 | 可以尝试投降（失败，但增加深度） |
| 后果 | 无 | 战争领主死亡后，镇民有评论 |

### Zhar the Mad（疯狂的Zhar）

| 要素 | 原版 | 优化后 |
|---|---|---|
| 对话 | 有对话 | 保留并增强对话 |
| 环境 | 图书馆 | 更多叙事细节（书籍、笔记、实验器材） |
| 选择 | 无 | 可以尝试偷书或索要（触发战斗） |
| 后果 | 无 | Zhar死亡后，镇民有评论 |

### Gharbad the Weak（弱小的Gharbad）

| 要素 | 原版 | 优化后 |
|---|---|---|
| 对话 | 有4段对话 | 保留并增强对话 |
| 环境 | 位置 | 更多叙事细节（他的物品、他的恐惧） |
| 选择 | 无 | 可以尝试放过他（他可能会帮助玩家） |
| 后果 | 无 | 放过Gharbad有好处（他可能会在后面帮助玩家） |

## 任务奖励设计

### 设计原则

| 原则 | 说明 |
|---|---|
| 有意义 | 奖励改变游戏体验 |
| 持久 | 奖励永久有效 |
| 有选择 | 在有意义的地方提供选择 |
| 不重复 | 不是每个任务都有选择 |

### 商人任务奖励

**Adria（女巫）— 蘑菇任务**

| 选择 | 奖励 | 适合谁 |
|---|---|---|
| 实用技巧 | 学习回城术（无视魔法要求） | 战士、游侠 |
| 禁咒 | 学习高级法术（需要魔法要求） | 法师 |

**对话**：
"我可以破格教授你一些实用技巧，或者某项禁咒，但这需要一些天赋才能掌握，你怎么选？"

**Pepin（治疗师）— 毒水任务**

| 奖励 | 说明 |
|---|---|
| 再生药剂 | 永久缓慢回血 |

**对话**：
"我研究出了一种再生药剂，喝下它你会永久缓慢恢复生命。作为感谢你解决毒水问题的谢礼。"

**Griswold（铁匠）— 铁砧任务**

| 奖励 | 说明 |
|---|---|
| 定制武器 | 玩家选择武器类型 |

**对话**：
"我用你找到的铁砧打造了一把武器，告诉我你想要什么类型的，我来定制。"

**Wirt（男孩）— 特殊任务**

| 奖励 | 说明 |
|---|---|
| 稀有物品 | Wirt收藏的宝贝 |

**对话**：
"这是我从地牢里找到的宝贝，送给你作为感谢。"

## 设计支柱检查

| 支柱 | 符合？ | 说明 |
|---|---|---|
| 支柱 1：不安感 | ✅ | 任务有黑暗氛围 |
| 支柱 3：环境是角色 | ✅ | 任务融入环境叙事 |
| 支柱 4：简单但深刻 | ✅ | 系统简单（任务+奖励），决策深刻（选择） |
| 支柱 5：尊重玩家 | ✅ | 玩家有选择，不是被迫 |

## 红线检查

- [x] 没有让玩家觉得自己是英雄（任务有道德模糊性）
- [x] 没有给玩家"赢"的感觉（选择有代价）
- [x] 没有打断沉浸感（对话自然）
- [x] 保持了稀缺感（奖励不是免费的）
- [x] 符合世界观（任务符合D1的黑暗氛围）

## 关键洞察

1. **不是每个任务都需要选择** — 只在有意义的地方提供选择
2. **奖励要多样化** — 不只是装备，还有能力解锁、消耗品等
3. **对话要自然** — 选择像真人交流，不是机械菜单
4. **任务要融入叙事** — 任务是故事的一部分
5. **克制是美德** — 不是加更多，是加得更好

## 与其他系统的关系

| 系统 | 关系 |
|---|---|
| 叙事系统 | 任务是叙事的一部分 |
| 消耗品系统 | 奖励包括消耗品 |
| 法术系统 | 奖励包括法术学习 |
| 装备系统 | 奖励包括装备 |

## 待验证

- 新增任务是否融入叙事？
- 任务奖励是否足够有意义？
- 任务选择是否有足够的后果？

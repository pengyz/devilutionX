# 任务系统

> D1 的任务系统已经相当成熟，但部分任务比较肤浅（纯杀怪），任务奖励不够有意义。我们需要优化现有任务，增加任务深度，并设计有意义的奖励。

## D1 任务系统现状（事实）

### 任务分布

| 层 | 任务 | 数量 |
|----|------|------|
| 教堂（1-4层） | Butcher, Poisoned Water, Ogden's Sign, Gharbad, Skeleton King | 5 |
| 地下墓穴（5-8层） | Magic Rock, Halls of the Blind, Chamber of Bone, Valor, Black Mushroom, Zhar | 6 |
| 洞穴（9-12层） | Anvil of Fury, Warlord of Blood | 2 |
| 地狱（13-16层） | Lachdanan, Lazarus, Diablo | 3 |

### 问题

| 问题 | 说明 |
|------|------|
| 分布不均 | 墓穴 6 个，洞穴只有 2 个 |
| 后期薄弱 | 洞穴和地狱任务较少 |
| 部分任务肤浅 | Butcher、Skeleton King 等纯杀怪 |
| 奖励不够有意义 | 奖励多为随机装备 |

## 设计原则

| 原则 | 说明 |
|------|------|
| 融入叙事 | 任务是故事的一部分 |
| 均匀分布 | 每层 2-3 个任务 |
| 有意义的选择 | 选择有后果，没有绝对对错 |
| 有意义的奖励 | 奖励改变游戏体验 |
| 克制 | 不是加更多，是加得更好 |

## NPC 评论深化（可实现）

### 评论类型

| 类型 | 触发条件 | 例子 |
|------|---------|------|
| 装备评论 | 玩家有更好的装备 | "那把剑看起来很锋利" |
| 进度评论 | 玩家到达新的层 | "你去过洞穴了？小心那里" |
| 健康评论 | 玩家血量低 | "你看起来很疲惫" |
| 任务评论 | 任务进度变化 | "你找到了那个东西吗？" |
| 背景评论 | 随机触发 | "我听说地牢里有..." |

### 评论克制原则

| 原则 | 说明 |
|------|------|
| 不是每次对话都评论 | 只有特殊情况下评论 |
| 评论有信息量 | 不是废话 |
| 不打断流程 | 不强迫玩家听 |

## 任务奖励设计

### 设计原则

| 原则 | 说明 |
|------|------|
| 有意义 | 奖励改变游戏体验 |
| 持久 | 奖励永久有效 |
| 有选择 | 在有意义的地方提供选择 |
| 不重复 | 不是每个任务都有选择 |

### 商人任务奖励

**Adria（女巫）— 蘑菇任务**

| 选择 | 奖励 | 适合谁 |
|------|------|--------|
| 实用技巧 | 学习回城术（无视魔法要求） | 战士、游侠 |
| 禁咒 | 学习高级法术（需要魔法要求） | 法师 |

**Pepin（治疗师）— 毒水任务**

| 奖励 | 说明 |
|------|------|
| 再生药剂 | 永久缓慢回血 |

**Griswold（铁匠）— 铁砧任务**

| 奖励 | 说明 |
|------|------|
| 定制武器 | 玩家选择武器类型 |

## 纯杀怪任务优化

### Butcher（屠夫）

| 要素 | 原版 | 优化后 |
|------|------|--------|
| 对话 | 无 | 屠夫有对话（"你来这里找死吗？"） |
| 环境 | 血迹 | 更多叙事细节（尸体、刑具、日记） |
| 选择 | 无 | 可以尝试逃跑（屠夫会追击） |
| 后果 | 无 | 屠夫死亡后，镇民有评论 |

### Skeleton King（骷髅王）

| 要素 | 原版 | 优化后 |
|------|------|--------|
| 对话 | 无 | 骷髅王有对话（关于他的疯狂） |
| 环境 | 宝座 | 更多叙事细节（破碎的王冠、腐化的徽章） |
| 选择 | 无 | 可以尝试说理（失败，但增加深度） |
| 后果 | 无 | 骷髅王死亡后，镇民有评论 |

## 与其他系统的关系

| 系统 | 关系 |
|------|------|
| 叙事系统 | 任务是叙事的一部分 |
| 消耗品系统 | 奖励包括消耗品 |
| 法术系统 | 奖励包括法术学习 |
| 装备系统 | 奖励包括装备 |

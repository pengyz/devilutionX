# 设计决策：环境光影系统

**日期**：2026-07-06
**状态**：已批准
**决策者**：pengyz

---

## 核心认知

D1 的光影系统比我们最初认知的更完备。它通过光照等级（0-15）和动态光源系统实现了氛围营造。我们不需要重新设计光影系统，只需要调整参数和增加环境光照压制。

## D1 光影系统现状

### 光照等级

- 0 = 最亮
- 15 = 全黑

|---|---|---|
| 玩家 | 10（基础） | 装备可修改，范围[2,15] |
| 火把（静态） | 8 | 烘焙在地图上 |
| 蜡烛（静态） | 3-5 | 烘焙在地图上 |
| 独特怪物 | 3 | 动态光源 |
| 狂暴怪物 | 3（巢穴9） | 动态光源 |
| Firebolt | 8 | 跟随弹道 |
| Fireball | 8 | 爆炸时增至12 |
| Lightning | 4 | |
| Nova | 8 | |
| 回城卷轴 | 15（最亮） | |

### 黑暗的效果

| 效果 | 说明 |
|---|---|
| 看不到怪物 | 黑暗中的怪物不可见 |
| 不能选中怪物 | 无法攻击黑暗中的怪物 |
| 怪物仍可能行动 | 怪物激活半径 > 玩家视野时，怪物在玩家视野外行动 |
| 不影响战斗数值 | 不影响伤害、命中、防御 |

## 设计方案

### 1. 降低光源亮度

| 光源 | 原半径 | 建议半径 | 理由 |
|---|---|---|---|
| 玩家 | 10 | 8 | 让周围更暗 |
| 火把 | 8 | 5 | 火把不再是"安全区" |
| 蜡烛 | 3-5 | 2-3 | 更微弱 |

### 2. 环境光照压制

某些层有"黑暗能量压制"，降低所有光源亮度。

| 层 | 光照倍率 | 玩家光半径 | 火把半径 | 氛围 |
|---|---|---|---|---|
| 教堂 | 100% | 8 | 5 | 正常 |
| 洞穴 | 80% | 6 | 4 | 稍暗 |
| 地狱 | 60% | 5 | 3 | 很暗 |
| 墓穴 | 50% | 4 | 2 | 极暗 |

**实现方式**：
```
实际光半径 = 基础光半径 × 环境光照倍率
```

### 3. 对抗措施

光是选择，不是必须。暗层可以无光通过，只是更难。

#### 现有装备

D1 已有 `_iPLLight` 属性（每点+10%光照显示）。让玩家更重视这个属性。

#### 新增消耗品

| 消耗品 | 效果 | 持续时间 | 获取方式 |
|---|---|---|---|
| 光明药水 | +3光半径 | 离开当前层后消失 | 购买/掉落 |
| 光明卷轴 | +5光半径 | 离开当前层后消失 | 购买/制作 |

#### 新增法术

| 法术 | 效果 | 持续时间 | 职业 | 获取 |
|---|---|---|---|---|
| 光明术 | +4光半径 | 离开当前层后消失 | 法师 | 法术书 |

### 4. 怪物激活半径机制

**问题**：原版D1中，怪物在不可见时不做任何事。如果光照压制只影响玩家视野，暗层的怪物会变得"迟钝"，降低紧张感。

**设计**：怪物激活半径使用玩家当前视野+2，而不是玩家基础光半径。

**公式**：
```
怪物激活半径 = 玩家当前视野 + 2
```

**场景分析**：

| 场景 | 基础光半径 | 压制倍率 | 装备加成 | 玩家视野 | 怪物激活 | Delta |
|---|---|---|---|---|---|---|
| 教堂（无压制） | 8 | 100% | 0 | 8 | 8 | 0 |
| 墓穴（50%压制） | 8 | 50% | 0 | 4 | 6 | 2 |
| 墓穴+光装备 | 8 | 50% | +2 | 6 | 8 | 2 |
| 墓穴+更多光装备 | 8 | 50% | +6 | 10 | 10 | 0 |

**设计效果**：

| 效果 | 说明 |
|---|---|
| 暗层更危险 | 怪物在玩家视野外行动 |
| 不会太挫败 | Delta只有2格 |
| 光装备有价值 | 减少Delta，降低危险 |
| 保持紧张感 | 仍然比正常层更危险 |

**数值说明**：
- 当前Delta=2是初始值，后续可以根据测试调整
- 如果太难，可以减少Delta（改为+1）
- 如果太简单，可以增加Delta（改为+3）

## 设计原则

| 原则 | 说明 |
|---|---|
| 黑暗增加危险 | 怪物激活半径 > 玩家视野时，怪物在玩家视野外行动 |
| 光是稀缺资源 | 不是到处都有 |
| 光是选择 | 不是必须，暗层可以无光通过 |
| 层之间有差异 | 每个层有不同的光照体验 |

## 设计支柱检查

| 支柱 | 符合？ | 说明 |
|---|---|---|
| 支柱 1：不安感 | ✅ | 暗层更紧张，黑暗中的不确定性 |
| 支柱 2：稀缺 | ✅ | 光明资源在暗层稀缺 |
| 支柱 3：环境是角色 | ✅ | 环境直接影响玩家能力 |
| 支柱 4：简单但深刻 | ✅ | 系统简单（光照倍率），决策深刻（带什么装备） |
| 支柱 5：尊重玩家 | ✅ | 有应对措施，玩家有选择 |

## 红线检查

- [x] 没有让玩家觉得自己是英雄（暗层更难）
- [x] 没有给玩家"赢"的感觉（需要准备和策略）
- [x] 没有打断沉浸感（光影是自然的，不是人工的）
- [x] 保持了稀缺感（光明资源稀缺）
- [x] 符合世界观（黑暗能量压制符合D1设定）

## 关键洞察

1. **D1光影系统已完备** — 光照等级、动态光源、视野系统都已实现
2. **黑暗只影响视野** — 不影响战斗数值，这是D1的设计选择
3. **环境光照压制** — 通过倍率系统实现层之间的差异
4. **光是选择不是必须** — 暗层可以无光通过，只是更难
5. **消耗品持续到离开层** — 有意义的持续时间，不是30秒/60秒

## 与其他系统的关系

| 系统 | 关系 |
|---|---|
| 资源系统 | 光明资源在暗层稀缺 |
| 消耗品系统 | 光明药水/卷轴是新的消耗品类型 |
| 法术系统 | 光明术是新法术 |
| 装备系统 | +光半径属性更有价值 |

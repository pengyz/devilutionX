# 设计决策：战斗系统

**日期**：2026-07-06
**状态**：已批准
**决策者**：pengyz

---

## 核心认知

D1 的战斗系统已经相当成熟。我们不需要重新设计战斗系统，只需要整合前序系统的设计，并确认战斗节奏和职业差异。

## D1 战斗系统现状

### 怪物AI系统

D1 有40种怪物AI类型，包括：
- 简单近战：Zombie、SkeletonMelee、Fat/Overlord、Butcher
- 远程：SkeletonRanged、GoatRanged、Succubus、FireBat等
- 冲锋：Rhino、Bat、Snake
- 特殊：Scavenger（吃尸体回血）、Gargoyle（石化自愈）、Sneak（隐身）、Counselor（传送施法）
- 群体：Fallen（战吼激励盟友、盟友死亡逃跑）

### 怪物行为特点

| 特点 | 说明 |
|---|---|
| 可见性门控 | 怪物在不可见时不做任何事 |
| 距离分支 | 不同距离有不同行为 |
| 随机机会门控 | 怪物有时会暂停或失败 |
| 领导者/追随者 | 怪物以群体工作 |
| 难度缩放 | 噩梦/地狱难度倍率 |

## 设计原则

| 原则 | 说明 |
|---|---|
| 保持D1节奏 | 慢节奏，每个动作有重量 |
| 整合前序系统 | 光影、消耗品、法术、任务 |
| 职业差异化 | 每个职业有独特的战斗体验 |
| 简单但深刻 | 系统简单，决策深刻 |

## 战斗系统整合

### 1. 怪物激活半径

**机制**：怪物激活半径 = 玩家当前视野 + 2

**效果**：
- 暗层更危险：怪物在玩家视野外行动
- 光装备有价值：减少Delta，降低危险
- 保持紧张感：仍然比正常层更危险

**数值**：
- 当前Delta=2，可根据测试调整

### 2. 消耗品战斗使用

| 消耗品 | 使用时机 | 效果 |
|---|---|---|
| 血瓶 | 战斗中 | 立即恢复生命 |
| 蓝瓶 | 战斗中 | 立即恢复法力 |
| 控制卷轴 | 战斗中 | 控制怪物（石化、减速等） |
| 伤害卷轴 | 战斗中 | 造成伤害 |
| 附魔油 | 战斗前 | 武器附魔 |
| 陷阱 | 战斗前 | 放置地面陷阱 |

### 3. 环境与战斗

| 环境元素 | 战斗效果 |
|---|---|
| 光照压制 | 减少玩家视野，增加怪物激活Delta |
| 地面危险物 | 走过受伤（火焰、毒液、尖刺） |
| 门/走廊 | 可以堵门、卡位 |
| 地形 | 影响移动和视线 |

### 4. 任务奖励与战斗

| 奖励 | 对战斗的影响 |
|---|---|
| 回城术（Adria） | 可以逃离战斗 |
| 高级法术（Adria） | 更多战斗选择 |
| 再生药剂（Pepin） | 被动回血，增加生存 |
| 定制武器（Griswold） | 更高伤害 |
| 稀有物品（Wirt） | 各种增益 |

## 战斗节奏

| 设计 | 说明 |
|---|---|
| 保持D1的慢节奏 | 每个动作有重量 |
| 不加速 | 保持紧张感 |
| 不减速 | 保持流畅性 |

**D1的节奏已经很好**，不需要改变。

## 位置机制

| 设计 | 说明 |
|---|---|
| 位置影响战斗 | 近战需要靠近，远程需要距离 |
| 门/走廊有战术价值 | 可以堵门、卡位 |
| 不是"位置稀缺" | 位置是战术，不是资源 |

**位置的作用**：
- 战士：需要靠近怪物，但可以利用门/走廊
- 游侠：需要距离，可以风筝怪物
- 法师：需要距离，但有法术可以控制

## 难度曲线

| 层 | 难度来源 |
|---|---|
| 教堂 | 怪物弱，数量少 |
| 洞穴 | 怪物变强，数量增加 |
| 地狱 | 怪物很强，数量很多 |
| 墓穴 | 怪物极强，光照压制 |

**难度增加方式**：
- 怪物属性（HP、伤害、AC）
- 怪物类型（更危险的怪物）
- 怪物数量（更多怪物）
- 环境因素（光照压制）

## 职业战斗差异

| 职业 | 战斗风格 | 决策重点 |
|---|---|---|
| 战士 | 近战，坦克 | 拉怪策略、位置选择、消耗品使用 |
| 游侠 | 远程，灵活 | 目标选择、走位、箭矢管理 |
| 法师 | 法术，脆皮 | 法术选择、法力管理、位置保持 |

**设计原则**：
- 每个职业有独特的战斗体验
- 决策深度不同，但都有意义
- 没有"最优职业"，只有不同玩法

## 设计支柱检查

| 支柱 | 符合？ | 说明 |
|---|---|---|
| 支柱 1：不安感 | ✅ | 暗层更危险，怪物激活半径机制 |
| 支柱 2：稀缺 | ✅ | 消耗品稀缺，需要管理 |
| 支柱 3：环境是角色 | ✅ | 环境影响战斗（光照、危险物） |
| 支柱 4：简单但深刻 | ✅ | 系统简单，决策深刻 |
| 支柱 5：尊重玩家 | ✅ | 玩家有选择，有应对措施 |

## 红线检查

- [x] 没有让玩家觉得自己是英雄（战斗很危险）
- [x] 没有给玩家"赢"的感觉（需要策略和准备）
- [x] 没有打断沉浸感（战斗是自然的）
- [x] 保持了稀缺感（消耗品稀缺）
- [x] 符合世界观（战斗符合D1的黑暗氛围）

## 关键洞察

1. **D1战斗系统已成熟** — 40种AI类型，丰富的怪物行为
2. **保持D1节奏** — 慢节奏，每个动作有重量
3. **整合前序系统** — 光影、消耗品、法术、任务都影响战斗
4. **职业差异化** — 每个职业有独特的战斗体验
5. **难度曲线自然** — 通过怪物属性、类型、数量、环境增加难度

## 与其他系统的关系

| 系统 | 关系 |
|---|---|
| 资源系统 | 法力、血量、消耗品影响战斗 |
| 法术系统 | 职业能力影响战斗方式 |
| 环境光影系统 | 光照压制影响战斗危险度 |
| 消耗品系统 | 消耗品是战斗的重要工具 |
| 任务系统 | 任务奖励影响战斗能力 |

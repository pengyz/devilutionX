# 战斗系统

> D1 的战斗是慢节奏的。慢不是缺点，是特点。问题不是"太慢"，而是"太重复"。

## 怪物 AI 分类（事实）

D1 有 40 种怪物 AI 类型，包括：

| 类型 | 怪物 | 行为特点 |
|------|------|---------|
| 简单近战 | Zombie, SkeletonMelee, Fat/Overlord, Butcher | 直线冲向玩家 |
| 远程 | SkeletonRanged, GoatRanged, Succubus, FireBat | 站在远处射击 |
| 冲锋 | Rhino, Bat, Snake | 快速冲向玩家 |
| 特殊 | Scavenger（吃尸体回血）、Gargoyle（石化自愈）、Sneak（隐身）、Counselor（传送施法） | 有独特行为模式 |
| 群体 | Fallen（战吼激励盟友、盟友死亡逃跑） | 有群体行为 |

### 怪物行为特点

| 特点 | 说明 |
|------|------|
| 可见性门控 | 怪物在不可见时不做任何事 |
| 距离分支 | 不同距离有不同行为 |
| 随机机会门控 | 怪物有时会暂停或失败 |
| 领导者/追随者 | 怪物以群体工作 |
| 难度缩放 | 噩梦/地狱难度倍率 |

## D1 战斗的真实体验（事实）

### 战士
- **前期**：站在怪物面前砍，偶尔喝血瓶
- **中期**：同上，但怪物更多
- **后期**：同上，但怪物更难砍
- **问题**：全程没有决策变化。"站着砍"从第 1 层到第 16 层都一样。

### 法师
- **前期**：Firebolt 远程消耗，法力紧张
- **中期**：Lightning/Flash AOE 清怪
- **后期**：Chain Lightning/Nova 碾压
- **问题**：后期太容易。一旦法力充足，没有挑战。

### 游侠
- **前期**：远程安全输出
- **中期**：同上
- **后期**：同上
- **问题**：体验太单一。"站在远处射箭"从头到尾。

## 核心问题

D1 的战斗问题不是"太慢"，而是**缺少决策变化**。每场战斗的决策空间太小：
- 战士：砍还是不砍？
- 法师：用哪个法术？
- 游侠：站哪里射？

**现代 ARPG 的战斗决策**：走位、技能组合、资源管理、时机判断。D1 只有资源管理（喝血瓶）。

## 改进方向

### 1. 怪物行为深化

D1 有 40 种怪物 AI 类型，但大部分怪物的行为模式是"冲向玩家"。改进方向：

| 改进 | 具体做法 | 效果 |
|------|---------|------|
| 群体行为 | 怪物会包抄、分散、集中攻击 | 战斗更策略 |
| 环境利用 | 怪物会利用地形（堵门、卡位） | 走位更重要 |
| 状态反馈 | 怪物受伤后行为变化（逃跑、狂暴） | 战斗更有层次 |

### 2. 环境互动

D1 的环境主要是视觉背景。让环境成为战斗的一部分：

| 环境元素 | 战斗效果 |
|---------|---------|
| 走廊 | 可以堵门、卡位（已有） |
| 地面危险物 | 走过受伤（火焰、毒液） |
| 光照 | 暗处怪物更难发现（已实现光照压制） |
| 门 | 可以关门阻挡怪物 |

### 3. 战斗节奏

**当前**：同一节奏从头到尾。
**目标**：紧张 → 峰值 → 释放。

| 阶段 | 节奏 | 体验 |
|------|------|------|
| 探索新区域 | 紧张 | 不知道会遇到什么 |
| 遇到怪物群 | 峰值 | 必须做出决策 |
| 清完怪物 | 释放 | 安全感 |
| 遇到 Boss | 峰值 | 高强度战斗 |
| Boss 后 | 释放 | 成就感 |

### 4. 消耗品战斗使用

| 消耗品 | 使用时机 | 效果 |
|--------|---------|------|
| 血瓶 | 战斗中 | 立即恢复生命 |
| 蓝瓶 | 战斗中 | 立即恢复法力 |
| 控制卷轴 | 战斗中 | 控制怪物（石化、减速等） |
| 伤害卷轴 | 战斗中 | 造成伤害 |
| 附魔油 | 战斗前 | 武器附魔 |
| 陷阱 | 战斗前 | 放置地面陷阱 |

### 5. 环境与战斗

| 环境元素 | 战斗效果 |
|---------|---------|
| 光照压制 | 减少玩家视野，增加怪物激活 Delta |
| 地面危险物 | 走过受伤（火焰、毒液、尖刺） |
| 门/走廊 | 可以堵门、卡位 |
| 地形 | 影响移动和视线 |

## 设计支柱检查

| 支柱 | 符合？ | 说明 |
|------|--------|------|
| 支柱 1：不安感 | ✅ | 暗层更紧张，黑暗中的不确定性 |
| 支柱 2：稀缺 | ✅ | 战斗资源稀缺 |
| 支柱 3：环境是角色 | ✅ | 环境直接影响战斗 |
| 支柱 4：简单但深刻 | ✅ | 系统简单，决策深刻 |
| 支柱 5：尊重玩家 | ✅ | 玩家需要学习怪物行为 |

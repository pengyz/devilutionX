# Spell Tooltip UI Design Language

## 设计原则

基于 D2/D3/PoE/Last Epoch 的成熟设计语言，结合 DevilutionX 的技术约束。

### 核心理念

1. **信息金字塔**: 最重要的信息在最上面，玩家读取顺序：名称 → 核心数值 → 次要信息 → 描述
2. **颜色编码类别**: 颜色表示"这是什么类型的信息"，不是装饰
3. **渐进式披露**: 默认显示核心信息，Alt键显示详细公式
4. **视觉分段**: 像文章一样，段落之间有空行分隔

---

## 配色方案

| 颜色 | 含义 | 使用场景 |
|------|------|----------|
| **金色** | 标题/核心标识 | 法术名称、等级显示 |
| **白色** | 主要数值 | 伤害、治疗、法力消耗 |
| **灰色** | 次要信息 | 持续时间、速度、弹数等 |
| **黄色** | 升级预览 | "下一级" 区域 |
| **红色** | 警告/危险 | 负面效果、无法使用 |

**设计理由**: 
- 金色标题突出，一眼看到法术名
- 白色数值高对比度，易于阅读
- 灰色次要信息不抢视线，但需要时能找到
- 黄色升级预览明确表示"这里会变化"
- 红色警告引起注意

---

## 布局结构

```
┌────────────────────────────────────┐
│ 火焰弹                    (金色)   │ ← 标题
│                                    │
│ Level 5 / 15              (白色)   │ ← 等级信息
│ 伤害: 12 - 24             (白色)   │ ← 核心数值
│ 法力: 6                   (白色)   │ ← 核心数值
│                                    │
│ 速度: 26 像素/帧          (灰色)   │ ← 次要信息
│                                    │
│ 下一级:                   (黄色)   │ ← 升级预览区域
│   伤害: 12-24 -> 16-30    (黄色)
│   法力: 6 -> 5            (黄色)
│                                    │
│ 发射一枚火球...           (灰色)   │ ← 描述文字
│                                    │
│ 会降低最大耐久度!         (红色)   │ ← 警告
└────────────────────────────────────┘
```

### 分段规则

1. **标题与内容之间**: 空行分隔 (1行)
2. **核心数值与次要信息之间**: 空行分隔 (1行)
3. **次要信息与升级预览之间**: 空行分隔 (1行)
4. **升级预览与描述之间**: 空行分隔 (1行)
5. **描述与警告之间**: 空行分隔 (1行)
6. **同类信息内部**: 无空行，紧凑排列

## 信息分类

### 核心数值 (白色)
玩家决策必需的信息:
- 伤害范围 (Damage: X - Y)
- 治疗范围 (Heals: X - Y)
- 法力消耗 (Mana: X)

### 次要信息 (灰色)
辅助理解的信息:
- 持续时间 (Duration)
- 速度 (Speed)
- 弹数/数量 (Bolts)
- 吸收率 (Absorb %)
- 存活时间 (Lifetime)
- 特殊效果描述

### 升级预览 (黄色)
当前等级 → 下一级的变化:
- 伤害变化
- 法力变化
- 其他数值变化

### 警告 (红色)
负面效果或限制:
- "会降低最大耐久度!"
- "法力不足时消耗生命"
- "免疫: 石魔、暗黑破坏神、纳库尔"

## 特殊规则

### Level 0 (无法使用)
```
火焰弹 (金色)

Level 0 / 15 (白色)
法术等级 0 - 无法使用 (红色)
```

### 工具类法术 (无伤害)
```
传送 (金色)

Level 3 / 15 (白色)
法力: 35 (白色)

传送到光标位置 (灰色)
```

### Alt 键模式
按住 Alt 时，数值行显示公式:
```
伤害: Magic/8 + Lvl + 1 (白色)
法力: Base - (Lvl-1) * Adj (白色)
```

## 实现约束

当前 DevilutionX 的渲染引擎限制:
- 只支持 3 种字号: 12px, 24px, 30px
- 不支持粗体/斜体
- 不支持下划线
- 支持颜色和对齐

因此:
- 所有内容使用 12px 字号
- 通过颜色和空行创造层次感
- 通过缩进表示从属关系 (如升级预览缩进2空格)

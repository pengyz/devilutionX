# Spell Tooltip UI Design Language

## 设计原则

基于 D2/D3/PoE/Last Epoch 的成熟设计语言，结合 DevilutionX 的技术约束。

### 核心理念

1. **信息金字塔**: 最重要的信息在最上面，玩家读取顺序：名称 → 核心数值 → 次要信息 → 描述
2. **颜色编码类别**: 颜色表示"这是什么类型的信息"，不是装饰。只有 4 种颜色，不多不少
3. **渐进式披露**: 默认显示核心信息，Alt键显示技术细节（速度、持续时间、半径等）
4. **视觉分段**: 像文章一样，段落之间有空行分隔

---

## 配色方案

| 颜色 | 含义 | 使用场景 |
|------|------|----------|
| **金色** | 标题 | 法术名称（FloatingInfoString） |
| **白色** | 正文 | 所有内容：等级、伤害、法力、描述、特殊效果 |
| **黄色** | 变化 | 升级预览区域（"下一级"） |
| **红色** | 警告 | 负面效果、无法使用、法术限制 |

**设计理由**:
- 金色标题突出，一眼看到法术名
- 白色正文统一，不花哨，玩家专注于内容
- 黄色升级预览明确表示"这里会变化"
- 红色警告引起注意
- **不使用蓝色/绿色/灰色** — 颜色越少，信息层次越清晰

### 分段规则

1. **标题与内容之间**: 空行分隔 (1行)
2. **核心数值与次要信息之间**: 空行分隔 (1行)
3. **次要信息与描述之间**: 空行分隔 (1行)
4. **描述与升级预览之间**: 空行分隔 (1行)
5. **升级预览与警告之间**: 空行分隔 (1行)
6. **同类信息内部**: 无空行，紧凑排列

## 信息分类

### 默认显示（白色）
玩家做决策需要的信息:
- 等级 (Level X / 15)
- 伤害范围 (Damage: X - Y)
- 治疗范围 (Heals: X - Y)
- 法力消耗 (Mana: X)
- 特殊效果描述 (如 "击中附近所有敌人")
- 描述文字（来自 spelldat.tsv description 列）

### Alt 显示（白色）
技术细节，按住 Alt 才可见:
- 速度 (Speed: 26 px/tick)
- 持续时间 (Duration: 8 sec)
- 弹数 (Bolts fired: 5)
- 吸收率 (Mana absorbs: 95%)
- 存活时间 (Lifetime: 12 sec)
- Golem 护甲、命中率
- 搜索半径、宽度等

### 升级预览（黄色）
当前等级 → 下一级的变化（只在法术书显示）:
- 伤害变化 (Damage: 12-24 -> 16-30)
- 法力变化 (Mana: 6 -> 5)
- 其他数值变化
- 如果下一级无变化，该行不显示

### 警告（红色）
负面效果或限制:
- "Warning: reduces max durability!"
- "Costs HP if mana insufficient"
- "Immune: Golem, Diablo, Nakrul"
- "Mana set to 0 after use"

## 来源类型差异化

不同来源的法术显示不同信息：

| 信息 | Skill | Spell | Scroll | Staff |
|------|-------|-------|--------|-------|
| 标题格式 | "{name} Skill" | "{name} Spell" | "Scroll of {name}" | "Staff of {name}" |
| 伤害/治疗 | ✓ | ✓ | ✓ | ✓ |
| 法力消耗 | ❌ | ✓ | ❌ | ❌ |
| 等级显示 | ❌ | ✓ | ❌ | ❌ |
| 升级预览 | ❌ | ✓ | ❌ | ❌ |
| 卷轴/充能数 | ❌ | ❌ | ✓ | ✓ |
| 描述文字 | ✓ | ✓ | ✓ | ✓ |
| 警告 | ✓ | ✓ | ✓ | ✓ |

## 实现约束

当前 DevilutionX 的渲染引擎限制:
- 只支持 3 种字号: 12px, 24px, 30px
- 不支持粗体/斜体
- 不支持下划线
- 支持颜色（通过 UiFlags）和对齐

因此:
- 所有内容使用 12px 字号
- 通过颜色创造层次感（金色 > 白色 > 黄色 > 红色）
- 通过空行创造视觉分段
- 通过缩进表示从属关系（升级预览缩进2空格）
